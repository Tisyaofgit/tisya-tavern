# alpha.13 配套叙事预设

当前文件：`Tisya-TauriTavern-0.2.0-alpha.13.json`。在**聊天补全预设**中导入，适用于月潮扩展 alpha.13—alpha.17，先更新扩展并重启。alpha.17 沿用本文件，无须重新导入。

使用快捷菜单第一项“配置”：本模式／主题／世界／预设与 API／上下文与数据。主文风在世界页输入、检索、保存、再选择；未选择时不附加默认文风。模式扩展、标记和工作流增强同样先保存再选用。预设本身只保留固定身份与协议及动态装配入口，不含资源目录。

本模式页保存后，以其心声方向配置为准；尚未保存方向覆盖时沿用当前原生预设开关。结构化输出的总开关仍是原生“输出 · 十块结构”。关闭可选内容不改变原协议的合法空容器。

通用、模式和任务的 API／预设分别继承。初次可都留空，继续使用原生当前连接与本预设。生成后通过“上下文一览”核对实际装配消息。配套叙事目前使用普通生成，Agent 适配接口预留。

原生角色卡正则可覆盖普通开场白及已解析的结构化正文。主题页默认允许该兼容路径，实际脚本启用和授权仍由宿主管理。扩展更新不会覆盖已导入的预设，仅更换 JSON 版本时需要手动导入并选用。

此预设依赖扩展的 `tisya_live_*`、`tisya_config_selected` 及原输出宏。没有对应扩展时不可作为独立预设使用。旧 alpha.10／alpha.12 文件保留供回溯。

alpha.14 在本模式页新增「思维链详细程度」三档：完整、精简、仅格式与配置。默认精简，保存后下一请求生效，配置随世界／聊天隔离。

alpha.15 将记录校验与公开面板读取分开。alpha.16 接入 A–E／a–e 和权限栏公开标记 ~，撤销强制四格提示；已有精细权限继续有效。无对应目标的权限行单独提示，不再阻塞独立有效的记录。关闭 MVU 时同步移除相反的操作模板。

alpha.17 将开篇输入评价／回应用户与收篇剧情吐槽分开装配，保持三档及关闭方向的配置。动态宏入口未变；更新扩展后下一条新回复生效。角色卡正则扩展显示、缓存、旅程滑动和旧附加权限定位兼容随扩展更新。
