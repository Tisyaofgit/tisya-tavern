# 缇斯亚 · 酒馆配套预设

`Tisya-TauriTavern-0.2.0-alpha.7.json` 是 **聊天补全预设**。先更新月潮扩展至 0.2.0-alpha.7 并重启，再在酒馆的聊天补全预设栏导入、选用此文件。

全局月潮外观仍用于所有角色卡。此预设提供缇斯亚的身份、叙事规则和十块输出；其他预设生成的普通正文也会使用同一外观。

## 本次接通的内容

- 保留 r243 配套 0.11.2 的身份文本、条目角色和顺序；顶部 system，尾部 assistant 确认、system 警告、system 交付触发。
- 使用原编译器将基础叙事配置展开为酒馆可直接读取的提示词，去掉 Tavo 的 EJS 与 getvar 装配依赖。条目正文仍可在原生预设编辑器修改。
- 原生世界书、玩家身份、角色描述、性格、场景、示例和聊天历史保留为酒馆原生槽，读取当前会话内容。
- “输出 · 十块结构”开关同时控制普通／结构化交付与末尾警告。扩展提供两个原生宏 `tisya_output_kind`、`tisya_delivery_warning`，只读当前预设的条目与顺序开关；返回原生界面后仍可使用。
- 正文美化条目说明标题、信笺、档案、密档和收获的写法。密档只是折叠样式，权限要求保持不变。

默认配置由原版建议值编译：互动叙事、不代写玩家、第三人称、限知、自然小说、2000—5000 字、4—6 个行动；摘要开、心声关、MVU 关。来源、哈希和完整配置见 `provenance.json`。

## 格式与测试

结构顺序沿用原版：`task → title → body → next → status → extra → vars → archive → memory → actions`，外层为 `<reply>…</reply>`。新生成采用 `format="pipes"` 固定列。显示解析保留原有旧格式兼容。

扩展目前展示标题、正文、行动和已获读者权限的回合记录；task、审计和私密记录不会作为正文后备显示。解析成功不代表状态已经提交。

1. **直接试美化**：将 `examples/prose-demo.txt` 内容作为普通 User 消息发送到测试聊天。应看到居中标题、信笺、档案、可展开密档和收获卡。
2. **试完整协议**：在测试聊天编辑一条 AI 消息，将其内容替换为 `examples/reply-demo.txt` 全文并保存。应看到“雾港来信”场景头、6 段正文、4 个行动；旅程手记内有一条公开记录。该短样例仅测显示，不请求模型。

## 移植边界

这是基础叙事配套版。原 Tavo 设置页的实时编译、图鉴绑定、记忆召回、工具回执和状态提交尚未接入。对应预设资料槽保留为空且可编辑；本版不从旧 Tavo 存档初始化，也不自动切换、覆盖用户所选预设。

已验证原编译器展开、输出开关联动、完整样例解析及 APK 前端排版；真实模型请求和 Android 导入仍待实测。普通卡的原生交互组件继续保留宿主管理。
