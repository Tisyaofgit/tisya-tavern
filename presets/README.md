# 缇斯亚 · 酒馆配套预设

`Tisya-TauriTavern-0.2.0-alpha.10.json` 是 **聊天补全预设**。先更新月潮扩展至 0.2.0-alpha.10 并重启，再在酒馆的聊天补全预设栏导入、选用此文件。

全局月潮外观仍用于所有角色卡。此预设提供缇斯亚的身份、叙事规则和十块输出；其他预设生成的普通正文也会使用同一外观。

## 心声方向开关

在原生聊天补全预设的提示词列表中分别切换：

- 心声 · 输入评价
- 心声 · 回应用户评价
- 心声 · 剧情吐槽

这些条目是空内容开关，保持内容为空即可。方向选择由原生条目和当前角色的提示词顺序共同决定；条目或顺序关闭都视为关闭。三项全关时，首尾心声均要求关闭；旧消息不会被回写。仍需打开“输出 · 十块结构”才能按结构展示新回复。

alpha.8／alpha.9 不会被自动覆盖，原先三方向仍保留；重新导入本文件后才有这些独立开关。全开、任意子集与全关共 8 种选择，和输出开／关组成的 16 种情况，均与原版编译器完整输出比对通过。

## 格式与测试

结构顺序沿用原版：`task → title → body → next → status → extra → vars → archive → memory → actions`，外层为 `<reply>…</reply>`。新生成采用 `format="pipes"` 固定列。显示解析保留原有旧格式兼容。

扩展展示标题、正文、首尾心声、核验、行动和已获读者权限的回合记录；内部任务字段和私密记录不会作为正文后备显示。核验展示回复中的短结论，不把模型自报当成运行验证结果。解析成功不代表状态已经提交。

1. **直接试美化**：将 `examples/prose-demo.txt` 内容作为普通 User 消息发送到测试聊天。应看到居中标题、信笺、档案、可展开密档和收获卡。
2. **试完整协议**：在测试聊天编辑一条 AI 消息，将其内容替换为 `examples/reply-demo.txt` 全文并保存。应看到“雾港来信”场景头、6 段隐藏段号的正文、首尾心声（点击气泡翻页）、7 项折叠核验、4 个行动及羽毛笔模式菜单、两页世界扩展和三张按短评配对的表情；旅程手记内有一条公开记录。该短样例仅测显示，不请求模型。旧样例里的“心声：关闭”仍遵守关闭含义；更新扩展不会改写旧消息。

## 移植边界

这是基础叙事配套版。三个心声方向已随原生预设实时切换；原 Tavo 的其他叙事设置实时编译、自建图鉴／角色绑定、记忆召回、工具回执和状态提交尚未接入。对应预设资料槽保留为空且可编辑；本版不从旧 Tavo 存档初始化，也不自动切换、覆盖用户所选预设。

已验证原编译器展开、输出开关联动、完整样例解析及 APK 前端排版；真实模型请求和 Android 导入仍待实测。已接入六种内置心声表情，配套预设从同一实际资源目录读取名称；没有合适表情时仍可用 null。旧版预设里固定为 null 的限制不会被扩展自动改写，需要导入新版。自定义表情资源尚未接入。普通卡的原生交互组件继续保留宿主管理。
