# 每轮表单与记忆确认 · 历史补录与三层上下文预览 v3

2026-11-15。用户已认可 v2 并补充历史补录，随后明确更正：**历史纪录是全会话已经确认的归档，旧 user 原文不再加入；三块中的同一信息点单次落位。** 本节为当前语义，下方 v2 验证仍保留其版本边界。

## v3 本次实现

| 层 | 内容与边界 |
| --- | --- |
| 历史纪录 | 当前会话、当前选中分支的已确认归档信息；保留独立认知和约定，不重新拼入远期 user 原文。 |
| 近期正文 | 用户选定消息窗口内较早的 char body／旧 boby 别名；去合法段号，以 history XML 包裹。排除旁栏、任务、机器归档等其他区块，并排除已放进最近情况的最新 char。 |
| 最近情况 | 最新 char 前一条 user＋最新 char 完整原文＋本轮 user 命令。完整保留所有区块和原始格式，不受近期正文条数影响。 |

历史条数沿当前配置含义，按历史 user／char 消息合计划窗，本轮输入另算。旧 user 只参与定位窗口，不进入前两层。设为 0 时近期正文为空，已确认独立归档与最近情况仍在。原始消息不被改写。正文边界异常会记录排除原因，不把整条机器区块兜底塞进正文。

信息点覆盖关系需核对来源版本、原文依据和人工确认；最新完整情况优先，其次近期正文，剩余独立归档进入历史纪录。相同来源中的不同知识不能一并删除，不按名字／话题做模糊去重。不同楼层的同一字段变化属于不同历史事实。程序只处理已核对的覆盖关系，不宣称无需语义核对即可消除原文中的全部复述；完整最近回复仍保持原样。长身份和校验值留在审计数据，不重复灌进提示词。

历史补录入口支持：

- 按表和字段分别勾选 cells／归档，选择起止或全部历史楼层；补录勾选与每轮规则分别保存，也可复制每轮勾选。
- 生成每层候选后，可编辑填写状态、所属记录、内容和原文依据；保存草稿不入档，明确核对后逐层确认。当前只有合成候选，没有调用模型。
- 完整原回复、段号、来源版本保留；确认前校验消息变化、原始副本、字段权限、值类型和范围。旧候选、重复覆盖、来源变化及缺项拒绝提交。
- 已确认覆盖按楼层、回复版本、字段及渠道记录；之后新勾选的字段只补缺项。一个字段可对应多条人物／对象记录，不把后续新增记录误当作旧候选重新提交。
- cells 补录记录历史当时值，不重放费用、奖励、动作或时钟，也不直接把历史数值覆盖当前状态。未知不填 0，未涉及不虚构对象。

新增 `engine/history-layers.mjs` 和 `engine/history-backfill.mjs` 是可复用的纯候选逻辑，本预览已调用。**它们尚未由正式 host、数据库或最终请求装配入口调用。** 输入的 scope 在正式适配时必须唯一覆盖 world／chat／branch，并提供当前分支的完整来源列表，不能只传近期窗口后误判远期来源被删除。正式接入需要让最终请求只使用一套历史通路；不能在原生历史和现有资料投影之外重复追加三层 XML。

- 按用户“永久、本世界”的要求，本版采用待定稿解释：**世界字段模板和每轮规则不随剧情回退删除；事实与记忆回退到所选楼层。** 回到新增字段之前，字段仍在、值为未记录；未来存档保留。覆盖v1“回退删除新字段定义”的演示行为。

## 使用与隔离

打开自包含 preview.html，或静态托管这一个文件。v3 的 index.html 是构建源，会导入仓库级读取模块，不再是可单独复制的静态入口。自包含页包含样式、目录、候选逻辑、脚本和字体，无CDN依赖；若本地文件存储被禁，使用静态预览。

从仓库根目录执行：

```bash
node preview/turn-review/build-catalog.mjs
python3 preview/turn-review/build-preview.py
node --test tests/history-layers.test.js tests/history-backfill.test.js preview/turn-review/model.test.mjs preview/turn-review/build-preview.test.mjs preview/turn-review/history-tools.test.mjs
```

目录生成器只读现有目录和权限；浏览器使用打包的共享正文读取器及纯候选逻辑，不读真实聊天。继续使用 localStorage 键 tisya-turn-review-prototype-v2，v3 增加 historyTools 可选状态，不重置已有 v2 字段与草稿，不覆盖v1。“重置演示”只重置本演示。正式版不会沿用此模型为第二份事实库。

初始有40、41轮存档和42轮候选，下一轮只推进合成测试数据；来源页标明后续轮次不是模型生成。示例引用为人可读占位，未做生产引用完整性校验。保存先持久化后更新页面；过期窗口写入拒绝。未确认不能继续；旧基线和重复确认拒绝。该模型不替代正式数据库事务、完整生产字段约束、多世界切换。
