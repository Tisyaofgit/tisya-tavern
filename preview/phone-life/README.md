# 生活手机 · 独立交互候选

这是供 UI 审阅的本机交互预览，包含八个应用及共享的故事时间、通知、搜索和存档。入口为 `dist/phone-life.html`，单文件内嵌脚本、样式及原创 SVG 插画；源码入口为 `index.html`。本候选独立于已交付的原虚拟手机预览，尚未接入酒馆宿主或正式运行链路。

## 从哪里开始

使用支持现代 JavaScript、localStorage、IndexedDB、文件选择和 HTML audio 的浏览器打开 `dist/phone-life.html`。首次进入会创建示例存档，之后继续使用同一浏览器、同一来源的本机存档。若浏览器限制本地文件存储，可在仓库根目录运行 `python3 -m http.server 8000`，再打开 `http://localhost:8000/preview/phone-life/dist/phone-life.html`。来源变化会形成另一份本机存档，因此先导出再迁移。

桌面打开应用，底栏切换常用入口。设置中可切换主号和小号、推进故事时间、推进一次社交回合、导入图片或音频，以及导出或导入完整存档。演示按钮只推进本地状态，不调用模型或真实服务。

## 八个应用与已实现边界

| 应用 | 当前可操作内容 |
| --- | --- |

| 云付（内页品牌「澄光」） | 零钱与银行卡、转账、信用消费与还款、借款报价与分期还款、模拟理财、资金流水。所有货币与金融产品属于故事内演示。 |
| 商城 | 商品详情、购物车、支付、订单阶段、收货、取消或退款，以及所得持有物。具体动作按当前订单状态限制。 |
| 外卖 | 餐食下单、支付、制作及配送阶段、领取与食用；食物进入持有物后使用，不直接假定已吃。 |

## 金额、报价和故事时间

金额在模型中统一使用整数「分」。借款必须先展示完整报价，再以同一 `quoteId` 确认；改动本金或期数不能沿用旧报价。演示借款年利率 APR 为 **12%**，可选 3、6、12 期，等额本金，无额外手续费，每期相隔 30 个故事日；逐期本金、利息与应还额均可查看，不能把首期金额误称为每期固定金额。

唯一模拟理财产品 `steady` 的演示年化率为 **1.8%**。只有明确点击「模拟结算收益」才按经过的故事分钟累计计算收益，向下取整到分，重复结算不会重复获利。赎回只返还本金和已经明确结算的收益。上述数值是候选的虚构规则，不代表真实金融产品或收益承诺。

设置中的时间按钮推进故事钟，页面显示的故事时间不是现实 UTC。出行和订单需满足各自时点与状态；真实时间经过、关页等待或重开页面不会被伪装成模型行动。

## 社交送达、隐私和手滑点赞

点赞依次记录 `queued → sent → accepted → notification-seen`。每点一次「推进社交回合」，只推进一个阶段。尚未送出的点赞可与取消合并；已经在途的取消会产生后续操作；已经读过的通知不会因取消被抹去，而会保留已撤回痕迹。这是本机模拟送达，不是实际网络消息或模型回复。

双击图片点赞默认关闭，可在设置中明确开启。普通点击不随机触发点赞。账号的草稿、关注、点赞、收藏与通知按当前账号区分；私密内容不会因切换自己的另一个账号自动公开。

导入图片默认私密。公开分享私密图片时需明确勾选授权；授权属于这条微博，原图仍保持私密。转发不能把不可公开的原帖变成公开内容。

## 图片、音乐与完整存档

内嵌示例图片是真实 SVG 插画，并有插画标识。用户导入的图片和音频原件存于本机 IndexedDB，状态只保存稳定媒体 ID；对象 URL 在当前页面创建，不能作为长期恢复地址。

示例歌曲只提供歌曲资料，**初始没有音源**。导入本地音频后才使用真实 HTML audio 播放，进度、时长及拖动取自实际播放器；不显示虚假的播放进度。可跨应用使用迷你播放器，并切换上一首、下一首、播放顺序和音量。实际可播放格式取决于浏览器解码能力。

设置的完整存档导出包含应用状态和已导入媒体原件；导入时先校验，再明确确认替换当前演示。缺失媒体会保留条目并说明缺失，不悄悄替换成样例。无效存档、写入失败或其他窗口已修改状态时保留原状态并显示错误；可导出原始存档和运行记录。临时试玩需要用户明确选择，关闭前请导出。浏览器清理数据会影响本机保存，JSON 导出才是可携带副本。

## 开发、验证与恢复

在已有依赖的仓库根目录运行：

```sh
node preview/phone-life/build.mjs
node --test preview/phone-life/core.test.mjs preview/phone-life/social.test.mjs preview/phone-life/bundle.test.mjs preview/phone-life/storage.test.mjs
```

`core.mjs` 管理资金、交易、物品、地图、日历和故事钟；`social.mjs` 管理账号、社交与媒体元数据；`utility-views.mjs` 和各 CSS 提供视图；`app.mjs` 管理交互、持久化、媒体及播放器；`assets.mjs` 提供 SVG 资源。`DATA-CONTRACT.md` 是实际核心动作与数据约定；`INTERFACE.md` 保留开发初始协作约定，其中早期示例动作名不能覆盖当前代码。每个持久操作使用唯一 ID 和参数指纹，同一 ID 的相同操作可重放，参数变更被拒绝。

最终原始测试记录为 `evidence/final-tests.tap`：**56/56 通过，0 失败、0 跳过**。这些是 Node、DOM/打包及存储竞争模拟验证；前期失败、修复与浏览器启动失败原件都保留在 `evidence/`。真实浏览器的整套交互与音频播放、酒馆宿主、真实模型调用、Android 实机均未验证。浏览器启动因缺少可执行文件失败，不能把 DOM 模拟当成真实浏览器通过。当前也没有真实支付、社交平台、配送、地图或音乐服务连接。

`PREVIEW-RESTORE.json` 列出本目录每个文件的大小、模式、SHA-256 与 Git blob SHA；清单排除自身，避免循环散列。恢复时使用最终保存回执的固定候选提交，恢复本目录后逐项核验清单；不要把父提交当成本轮预览提交。父基线固定为 commit `4586225b7e3e3e60a0ea6ab6f541b5ea4a13d61f`、tree `91db7cfa9961077804eef039992d330736300927`。
