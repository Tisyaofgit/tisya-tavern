## 十张内置文风卡

十卡正文更新为 v3，保持原 ID、名称、角色与凝视分类。克制心动侧重事务中的亲近余温；机锋往返侧重个人声口；日常质感侧重物件与生活过程。女凝保留主体的感官和判断，男凝保留视觉构图与审美停驻。char、user、观众三个凝视方向各守自己的关注对象与知情边界。留白卡由对白、停顿和细节承载潜台词；自然叙事卡让句式随注意和感受流动。

十卡通过已有配置资源与 OnePass 消费路径生效，只有当前所选卡进入请求。Matrix 主路径使用自己的偏好与基础提示词；本次两条路径分别修改和验证，没有把十卡自动全部加入 Matrix。

## 已有配置与用户修改

- 已存 v2 卡只有在稳定 ID、类型、角色、版本和完整旧正文都匹配，且没有外部来源时，才在读取视图中投影 v3 正文。名称、开关、任务、参数、选择与自定义字段保留。
- 自写正文、空正文、外部来源和未知卡版本保持原样，读取和编译不批量写回存储。
- 旧 Matrix 基础提示词以完整旧正文的 digest 精确识别后，在本次请求中投影新条款。用户编辑过的正文和显式保存的 prompt 覆盖不自动替换。
- 明确选择的偏好在 stock 投影之后应用，因此仍有同域覆盖权。修改过的旧提示词如果保留了旧约束，也会按用户文字保留。
