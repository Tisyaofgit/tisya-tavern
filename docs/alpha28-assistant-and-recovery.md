# alpha28 使用与修复范围

更新扩展到 **0.2.0-alpha.28** 后，完全关闭并重新打开应用。已有会话、原点书和存档继续使用，不用删除重建。

## 缇斯亚配置助手

入口：配置 → 表单推进 → 缇斯亚助手。

可以直接说“历史保留 15 条，先关闭剧情推进，把角色心理显示打开，消息下只留继续和更多”。助手读取当前配置及合法选项，列出每项修改前后值。点一次 **应用全部更改** 即可保存所有列出的修改。它不会在回答时保存或把建议当成已执行结果。

- 当前会话的模式参数、角色控制、选中资源、上下文范围、表单开关、辅助模式补充要求和文风规则。
- 通用／各任务／各模式的 API 连接引用、模型名、预设引用和请求参数。
- 已登记资源内容、Agent 方案引用、主题引用。
- 外观区块、角色心理显示、输入与消息快捷栏、常用语、联系人分组、桌宠、动态效果及继续消息。

这份权限面向缇斯亚已登记的配置。API 凭据与地址仍由宿主原生连接管理，助手只选择连接引用。缺少的新模式、新资源、新表或模板，助手整理到 **带着需求交给创世**，打开时已填入原需求。创世生成的蓝图仍能编辑再应用。不会让模型执行任意脚本，也不会用缺失字段冒充已接入功能。

助手使用独立的 `tableAssistant` 辅 API 路由，默认跟随主聊天连接；无需启用自动表单推进或成功绑定存档即可问配置问题。提问会发送本页列出的配置、模板、当前可读表行、楼层预览和诊断；不会自动发送其他会话、完整世界书或连接凭据。

尚未应用的建议遇到聊天／配置改变会停止，以免旧建议覆盖新设置。全部修改在保存前整体校验；保存失败不显示完成。存档初始化和补录仍沿用各自明确的操作按钮。

## 楼层补录

进入“历史补录”便显示真实楼层，即使世界书未就绪也可查看原文预览和填写手写历史。未读取到存档时显示 **未核对**，不会冒称未归档或零记录。

首次开始补录或点“重试初始化并核对归档”会创建／复用当前角色卡原点书和本会话存档。支持旧宿主要求的 `current` 角色绑定参数，保留现有主书和追加书。已创建但上次绑定失败的原点书会复用。

自动补录按原聊天楼层顺序处理 AI 回复；用户及系统消息计入原楼层序号。默认排除最新 AI 回复、跳过已归档层；无 memory 块也能使用正文。手写历史仍先生成可编辑草稿。每批上限 100 条，停止后已确认保存的楼层保留。

## 预设和表单都能查看

入口：表单推进 → **预设与表单全文**。

逐项展开七类辅助任务，查看内置身份、模式任务提示词、当前路由及本任务选中资源。每类任务都有单独的补充要求，保存后参与该模式的请求编译；正文叙事配置不随之改变。辅助输出依旧是 JSON，无心声和 reply 包装。

下方列出全部表／类型模板、字段类型、必填限制与实际已填记录。存档未就绪时显示内置初始模板，并明确标识读取状态。可导出完整预设与表单 JSON。自选原生预设的实际最终请求仍可在配置顶部“上下文一览”查看。

[本版完整内置提示词与基础表单](alpha28-presets-and-forms.md) 从代码生成，供安装前审阅；用户自定义内容以应用内预览为准。

## pipes 文本读取修复

`解锁：~|~|~` 是空可选记录，之前被当成三个必填文本而触发 `TISYA_PIPES_TEXT`，从而阻挡其他区块。现在空占位按不存在的可选解锁行读取；有实际内容但缺字段的解锁行仍会报告错误。生成提示词也要求省略空解锁行。

读取是临时视图，不改原始聊天文本、权限等级或变量操作。中性同结构回归同时覆盖数组名称列表、旧 status 权限注记、vars 中 UpdateVariable/JSONPatch 的 replace 与 delta。

## 改写按钮位置

保存、取消、上移、下移等原生编辑按钮统一放在编辑框下方。移动现有按钮，不复制或重建控件；保存和取消仍由宿主执行。退出编辑或返回原生界面时还原原位置，重复编辑和宿主重绘后重新定位。

## 验证边界

覆盖受限宿主模拟、原点书复用、切换保护、DOM 页面、配置前后差异与保存、助手请求路由、补录及结构解析。模拟 API 返回不是实际模型的可靠性证明；本版没有在用户 Android 安装环境或用户真实模型连接上运行。
