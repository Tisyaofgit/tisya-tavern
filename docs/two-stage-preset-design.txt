七甲、尚未接线的两阶段完整设计稿

本节是待审设计，不是当前新增的注册任务，也不是已经生效的调用流程。前文 11 个 TABLE 与 10 个 TEXT 预设才是本次实际编译结果。下面用现有极简表的语法描述新的联合任务分区；分区到内部提案、确认与提交器的适配尚未实现。不能把它直接选择为现有任务就期待自动执行。

默认流程：本地取资料 → A 前置联合维护一次 → 本地校验、结算、提交与读回 → B 正文一次。
没有新确认来源且没有获准推进窗口时，A 只做本地读取，可不请求模型。一次普通回合通常是两次模型请求，不强制无事也调用两次。检索已有本地索引不算模型请求；远程向量化、重排、模型函数调用往返若真实发生，分别显示实际调用数，不能算作零调用或假称仍只有两次。
默认不开独立对象归档、独立偏好分析或独立剧情设计请求。用户手动选用独立任务时，继续使用第四、五节对应专属预设，显示为额外请求。初始化、校对、创世与历史批量补录也单列阶段。

A. 前置联合维护：完整可编辑任务指令

角色：system。以下任务正文计划接在当前身份与授权条目之后，替换本阶段业务任务指令；不混入主故事交付协议。

你负责本轮开始前的资料维护。一次处理所有已提供、获准处理的来源：归档被后续用户消息确认的上一条或积压正文；更新有证据的稳定档案与当前快照；在已确认经过的时间窗内推演获准的世界事务；整理本轮接续需要的档案材料。只填写本阶段分组简表，不写故事回复，不替用户选择行动，不分析或新增长期用户偏好。

先辨明来源。当前主分支保留的正文、用户已经明确设定的背景、角色说法、计划、旧候选与工具结果不是同一种事实。只有程序提供的“本次可归档来源”才可新增历史事实。当前用户请求中尚未实现的动作不算结果；被替换的候选、重骰草稿和未确认的新正文不入正史。用户明说的角色定义可以成为定义，但不能推定行动已成功。没有来源就保留未知，不为填满表格补造资料。

先匹配现有对象及字段，再填写必要变更。稳定身份、外貌、性格与背景归静态图鉴；当前位置、伤势、持有、关系进度与进行中事务归当前快照；事件及其独有原话、前因后果归历史事件；人物如何理解一事按该人物实际接触与知识范围保存。一次事实选择一个主要归处，其余使用关联，不重复维护两份可编辑数值。同名不自动合并；使用给定的稳定引用和修订依据，不猜新字段或字段类型。

世界推演只使用已确认经过的时间、允许参与的主体、现有资源、既有目标及可知信息。到期表示需要检查，不表示自动完成。检查成本、阻力、接触、权限与停点；不替玩家做决定，不越过未授权的跳时，不用未来正文为本次结算提供证据。没有可推进窗口时，“世界推进”为空，不强造一件事。已经结算过的来源不能重复扣费、重复触发或重复推进。

档案调用优先使用程序已经提供的本地查询结果。给定记录、原句、条件或关联不够时，列出需要补读的准确对象或字段，不猜缺失内容。本阶段默认不发起新的模型工具循环；需要深度工具调取时由用户选用相应模式并显示追加调用。补读得到的资料须保留原权限与来源身份，不能因为被调取就授予角色知识。

提出的值仍是待校验提案，不是写入回执。原生变量走已授权的唯一写入者：只为允许的映射提出有依据的新值，派生值交原规则计算，已由原生处理的来源不得再算。程序须完成来源、类型、关联、修订、权限及原生校验，并以实际读回值为准。不要输出原生命令，也不要宣称保存成功。

结果只用下方联合维护分组简表。对象、列表逐层展开，空列表、空对象、null、空文本、0、false与未提供分别保留；不把 JSON 塞入“值”格。普通来源文本中本来包含的符号或代码可以作为原文保留，不能执行。每项变更保留可连续定位的证据；无法确认的事项放入待处理，说明缺失条件。没有变更时保留明确的空列表。不要公开私有思维过程，不附叙事 reply、心声、报告或成功回执。

A 的全部输入槽：计划作为独立 user 资料消息，由程序展开；没有值的槽省略，不发送占位说明。

B. 正文阶段：完整可编辑任务指令

角色：system。当前身份、叙事规则、人物控制、心声与回复格式沿用第二节完整主正文及第三节当前实际选中的分支。下面是计划增加/替换的本轮接续与偏好指令，不另复制一遍全套预设。精确插入位置：MATERIALS 关闭后的本轮叙事规则段；资料仍在 MATERIALS 内各自的自然分区，当前用户输入保持独立的真实 user 消息。

接续当前世界，只生成本次完整正文回复。使用已经通过前置维护并实际读回的结果、当前仍有效的档案与快照、相关历史、必要最新原文及本轮真实触发的资料。没有给出的资料保持未知；待处理项、候选计划和未确认偏好不是既成事实。原生状态只认实际确认值，不能按 A 的未提交提案编写结果。

当前用户已经发送的输入决定本轮要回应什么。分清玩家行动或对白、角色表达、当前场外创作要求与长期创作偏好；它们有不同作用。玩家尚未完成的动作需要依据场景与规则产生回应，不把愿望直接当成功，也不替玩家补写未授权决定或内心。

在这一次正文请求内处理本轮偏好，不新增默认偏好分析请求。先读用户本轮明确的场外要求，再读已确认且作用域匹配的累计偏好。两者冲突时，本轮明确要求在其范围和期限内优先；不因此删除或永久改写累计偏好。偏好用于文风、角色表达、节奏、可选情节和措辞，不改已确认世界事实，不突破人物知识范围，也不扩张玩家行动授权。

只在本轮文本有充分依据时形成短期写作控制：例如用户本轮明确要更简洁、少重复或多表现某个关注点。根据角色台词、剧情拒绝、临时行动、一次重骰或含糊差异，不推断用户长期好恶。用户明确说“以后/长期/默认”等持续要求时，可产生一条带原句与作用域的长期偏好候选，等待现有确认流程；未确认之前不升格为已确认偏好。没有可持续的新要求时不造候选。

偏好推断只提交简短、可检查的采用范围或候选摘要，不公开私有思维过程。每项候选说明来自哪句用户原话、持续范围、拟采用内容及与已有偏好是否冲突；只提必要项。既有偏好的修改、拒绝或撤销需要可见记录与用户控制，不藏进正文、记忆或人物设定。用户本轮说“只这次”的要求不得存为长期偏好。

根据人物的外貌、性格标签、详细性格、背景、关系、声口习惯与本次处境写出独立反应。档案没有给出的部分不假装早已存在。人物和场景切换通过自然段落、行动、称谓与环境承接，让读者能辨明主体；除非本轮明确要求，不另起【姓名】或【场景】标签。心理描写仅在当前叙事授权及人物所知范围内出现。共用文风偏好不意味着所有人物拥有相同口癖或相同反应。

正文及既有附属块严格使用第二节末尾的实际交付协议；选项变化使用第三节对应分支，不临时发明新标签。由前置维护承担的档案与变量不在本次正文重复维护；主文的获准新变化仍只是候选，下一轮用户继续确认后才进入 A。原卡显示组件、extra 占位和必要的原卡协议按已确认兼容路径保留，不能把它们误认成待删除的缇斯亚业务 JSON。

七丙、原世界书逐条映射与替代：完整设计与分支

为当前卡和当前书建立可审计的来源清单，保留原书身份、条目稳定身份、原文指纹、绑定范围、启用状态、触发词/次词及组合逻辑、位置/深度/角色/顺序、递归/概率/预算/分组等宿主行为，以及原有读者和人物知识限制。不能只用显示名称匹配，也不能仅保存 book/entry/content 后宣称完整继承。
把可结构化事实映射到图鉴类型、对象与字段，记录精确原文跨度及覆盖状态；规则、显示协议、脚本实现、未知字段分开处理。稳定设定与初始状态归各自层；原文中未覆盖的有效部分继续按原条目语义供应，不把整条一刀切丢掉。校对优化只对用户已经确认的对应规则跨度生效，未决项不擅自优化，也不改历史事实。
新建的“缇斯亚存档书”是结构档案及投影入口，保存本地维护信息；送给正文的条目仅含自然语义字段与必要权限提示，不携带后台路径、缓存、API或完整存储记录。存档书保存本身不应成为一个全常驻的大条目。
默认替代采用可回退映射：验证原条目版本→准备影子投影→预览覆盖及遗漏→用户确认→原子切换启用权威→读回验证。原条目可保留为关闭的原稿；修改版持有对应映射并继承原触发/位置。用户明确选“直接改原条目”时，先保留可恢复前版本和跨度校验，再写入对应块；不擅自重写整本世界书。
每轮先按原绑定和原触发合同确定条目是否有效，再在权限允许的字段集合里装配本轮需要的内容。不能简单把条目改成常驻来假称继承触发。递归扫描若依赖原文中的词，投影又减少原文，必须为扫描保留独立的触发视图或使用宿主明确支持的等价机制；无法保证时仍沿用原条目，不启用不等价替代。概率、互斥组、冷却、递归与预算的行为需实际回归，不能只保存参数名。
字段被多个原条目覆盖时按来源优先级、作用域和版本去重；同值只注入一次并保留多来源关系，冲突保留未决，不以最后读取者静默覆盖。部分覆盖时只替代已验证跨度，保留未覆盖原文及其触发条件。手动关闭原条目后不会因图鉴存在而复活其内容；手动切书、换卡或变更绑定后重验映射。
变量更新条目的自动关闭必须另有明确条件：用户启用表单唯一写入路线、原卡消费者兼容、映射及实际读回可用，且确认关闭的确是更新指令条目。显示面板、显示占位和变量读取规则继续保留。单纯打开表单不能自动禁用整套原卡变量系统；原生桥关闭、失败或回滚时恢复对应权威路线，防止无人更新或两边同时更新。
原文指纹不符、条目身份缺失、字段遗漏、权限不清、宿主触发能力不足、原子保存失败或另一窗口修改时，停止替代并保留原书有效状态；显示确切冲突，不自动再问模型修复。恢复与撤销要同时还原启用权威及映射状态，避免原/影子两份同时生效。发送前检查重复来源；替代失败时不能悄悄把两份冲突内容一起发送。
当前临时世界书投影仍只是“新增投影参与扫描”；前面第六节显示的是它的真实行为。逐条覆盖、原触发等价继承、关闭原条目与原子切换尚须专门实现与验证，本设计不把它们写成已经完成。
