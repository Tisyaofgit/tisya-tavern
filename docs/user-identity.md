# 用户身份与原点关联

从设置“用户身份”、主页 USER 或当前角色/群聊的“查看／切换身份”进入。设置与子页右上角“聊天 ›”直接回到当前聊天；未保存资料仍有离页保护。

已有原点按世界书、对象ID及版本选择，预览后将完整设定写入当前原生身份；原点原文与会话进度保留。人物基点加当前角色卡、自由点子两路先向所配AI生成完整草稿，用户核对后另存原点，再明确绑定。模型原答与编辑草稿可保留和导出；真实AI结果仍需审阅。

“使用并绑定”默认保存本聊天锁定及当前角色卡连接，群聊只连该群；全局默认需要单独勾选。原生persona目录是活动名称/设定/头像/注入的唯一真源，原点引用固定版本，会话账本负责当局进度。切换同世界原点身份同时更新当局人物关联；不改历史署名、不清空进度。跨世界身份要求先适配。

设置、聊天和档案写入分阶段核对；部分失败保留恢复标记，“继续核对绑定”可恢复，生成前拦截未完成切换。原点写回失败可在管理页“继续核对原点绑定”恢复。来源被删或版本不符会停止引用，不自动换人。原生完整控件保留头像裁切、复制删除、称号、注入位置、世界书、备份恢复和历史署名操作。

骰子偏移原因：五字中文标题令隐式网格列从44px扩至54px，图标右偏5px。固定列宽及长标题字距后，在消息栏和更多菜单、320/430/900宽下均居中；保留44px触摸宽度。

验证使用真实页面、服务与世界书适配器，隔离宿主/模型数据；自动回归和Chromium通过不代表Android文件权限、第三方扩展或实际模型质量已实测。
