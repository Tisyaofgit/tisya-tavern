# alpha27 · 辅助任务和自动配置

## 辅助输出

记忆归档、新发现建档、历史补录、剧情推进、偏好确认、创世设计使用直接 JSON。身份沿用缇斯亚；请求中只放本任务所需的资料槽及选中资源。没有首尾心声、叙事正文、七项审计或十块 reply 外层。原来的报告字数设置不再使用。

正文的心声表情、回复结构、变量归入 vars 的预处理与原生变量执行不改。旧辅助结果中的 extra/tisya_result 仍能读取，避免旧记录失效。

## 首次使用

表单关闭时不创建存档、不调用辅助 API。启用表单或首次打开表格、补录、创世等功能，会补建当前角色卡的原点书与本会话独立存档。再次使用、刷新或重试复用原书。已有手工绑定优先，不覆盖数据库插件的聊天世界书绑定。

自动确定原点书只用于单角色会话；多本候选时仍需明确选择，群组需先确定档案所属角色。

## 创世中的自动创建

进入「表单推进 → 创世与模板」，生成蓝图后展开「自动创建世界书／正则／预设」。可以增删、编辑名称、作用域、目标、条目和规则。无需时保持空列表。

- 世界书：编辑条目正文、关键词、蓝灯／绿灯和启用状态。
- 正则：编辑稳定 ID、查找式、替换内容、标志、处理来源、显示／提示词范围。
- 预设：新建命名预设和提示词，保留原生历史等占位槽，不复制当前 API 凭据。

确认应用蓝图后自动补建。先保存表格，再安装原生配置；不是跨文件事务。若后一步失败，蓝图和已完成项目仍保留，可点「检查／补建蓝图原生配置」重试。无需重新填写或重复应用表格。逐项结果可在「时间锚」查看。

同名预设、同名条目和相同 ID／名称的正则保持原值，缺少条目追加。已有内容需要修改时进入相应原生编辑器，不由自动补建覆盖。新预设不自动切换。

| 作用域 | 世界书 | 正则 |
| --- | --- | --- |
| 全局 | 追加到原生全局书单 | 原生全局规则 |
| 角色 | 追加角色书，保留主书 | 指定角色局部规则 |
| 预设 | 关联保存在该预设扩展字段，选中时参与原生扫描 | 指定预设规则 |

世界书原生没有预设绑定槽，以上预设关联由缇斯亚读取，不会改全局书单。重复关联会按书名及 UID 去重，仍受原生蓝绿灯、关键词与 token 预算约束。手选资料模式继续遵守用户所选资料范围，不借自动创建扩大最终请求。

角色目标使用头像 ID，预设目标使用实际名称；留空表示确认时的当前目标，保存后固定，重试不跟随新目标漂移。

新增正则不重开原本被禁用的已有作用域。已有脚本且局部开关关闭时，结果提示到原生正则页开启；原先为空的作用域可以随新规则自动开启。禁用的正则扩展也不会被擅自恢复。

依赖新版酒馆助手的 worldbook / preset / tavern_regex API，以及 TauriTavern 的预设扩展字段和世界书扫描事件。缺少接口会报出对应名称，保留数据及已完成结果。

## 验证

自动化覆盖六类实际编译请求、手动辅助模式、无表情目录、旧结果兼容、自动初始化、三种作用域、同名内容保留、幂等补建、切换保护、预设世界书去重、失败后的表格保存与补建、可视化字段及旧版本回归。请求快照为程序编译结果，没有真实调用用户模型；DOM 测试不代表 Android 实机验收。
