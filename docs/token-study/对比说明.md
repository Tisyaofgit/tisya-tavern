# 提示词语言 token 对比

完整 INNER 工作流块；三个清理后版本保留同一规则含义与输出协议，翻译说明文字；字段名、枚举、标识符保留。固定为同一中性宿主配置的实际装配样稿，不含角色卡、聊天历史、其他预设块及消息封装开销。

使用 tiktoken 0.14.0 实计；这不是供应商账单或生成质量测试。语言译本只作为实验材料，没有替换动态生成规则。

|---|---:|---:|

|清理后混合|12,010|11,143|
|全中文说明|15,664|12,317|

英文说明在两种编码下最少。中文字符更少，但 token 更多；不能用字符数或中英混排本身推断 token 开销。不同模型的 tokenizer 可能得出不同数值。

本轮清理：心声约束保留单一定义、六个模板格只留短占位、末尾复核只引用记录规则；权限注记及读者展示的重复解释改用引用。保留固定列、必需语法、阶段依赖及权限边界。
