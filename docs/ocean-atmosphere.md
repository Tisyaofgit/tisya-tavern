# 洋流、天候与水相发束 · R5 眼部与发束修订

2026-10-17 用户批准 R3 进入会话主页并替换聊天底图，随后要求雨雪随机、风扰、极轻点触破泡声及独立开关；追加男女水相头发自然轻微随机摆动。开发基线 `4c933df`，本工作分支不包含并行 W55 的提示词改动，未覆盖正式 main 或提升发布版本。

## 接入与设置

- `home-art.js` 与 `mountChatEffects` 均使用 `mountAtmosphere`；共享引擎、着色器与天气模块。聊天背景固定归外壳单例，消息删除不会重建它；主页打开时聊天场景暂停。主页移除旧静水底图读取和旧气泡绘制路径。
- R3 色调与材质完整保留。流向、速度和涡心随机后平滑过渡；稀疏随机雨点与涟漪、气泡破裂保留。系统“减少动态”优先，隐藏无时间追赶；同尺寸几何通知不清空画布。背景组合关闭时不保留空转 RAF，仅点触碎片存在期间短暂绘制；卸载主动释放 WebGL 上下文。
- 原有“背景特效模式”、水纹/涟漪/斜雨/落雪/萤火组合继续使用；雨滴、雪片各自出生时采样大小、落速和层次，受平滑随机风场影响，越界后重新采样。自动轮换仍淡入淡出。
- 原有“动态效果”与“动画效果”控制背景、雨雪和头发；关闭时显示静态洋流，移除粒子叠层。旧值 false 不会被重置。
- “旅程与聊天外观”增加“点触音效”，通过同一字段登记供设置与渲染读取；默认开启，最大增益 0.009，约 70ms，仅合格点触播放。声音独立于动画开关，可只留声音或只留动效。按钮、输入、选择文字、拖动、滚动和长按不触发。
- 音频只在用户手势后创建/解锁；关闭、后台及卸载使在途声音失效，迟到的解锁不补播旧点击。纯正弦短下降音，无网络音频资源。实际听感受设备音量影响。

## 水相

原女 V13 / 男 V14 肖像与眨眼原图字节保留。R5 用户否定男相虹膜清晰度并要求发束明显一些；旧的低幅刚性裁片方案在放大后露出缺口，已替换。每相仍是三组独立根部与随机目标，但以共用顶点连接发束，根部连续、自由端稍弯；不使用噪声液化、全脸网格或全身位移。仅小块发束绘制后整幅统一缩放，完整脸、远眼、颈与身体保持原像素。目标每 3.8–6.6 秒平滑变化，初次挂载从静止进入。

以显示宽度换算 CSS 参考毫米：单侧最大 2.5 mm，往返包络上限 5 mm；随机目标取包络的 65–100%，常见往返约 3–5 mm。不同发束几何与手机宽度还会进一步限幅，实际物理毫米取决于设备；不声称已在 Android 用尺校准。缩放时重新读取显示宽度，静止/减少动态直接保留原发束形态。

男相新增 `male-eye-detail.webp`，只遮罩两处眼内虹膜，原眼睑、眼型、脸型和视线不替换。细节由 imagegen 局部精修，再按原眼球位置配准；来源和重建脚本见 `eye-detail-provenance.json`。眨眼改为眼睑逐步遮住虹膜，避免两状态半透明叠加造成的糊影；全闭时不绘制精修虹膜。女相沿用原眨眼。男相加载 3 张、女相 2 张，尺寸不匹配明确报错。

## 验证与边界

相关 44 项模拟检查通过；实际 Canvas2D 绘制男女多时点，检测的完整脸颈区域与下部身体像素变化为 0；静止帧与原图像素一致。生产着色器在 Mesa GLES2 实际编译和绘制，含雨雪、涟漪与暂停。完整构建和测试结果以工作区最终记录为准。

完整套件最初出现 1 项新测试失败：把自然破泡算成点触次数。保留失败记录，改为检验独立点触计数，不改粒子行为。初次素材测试因旧版三张素材加载预期和未模拟 WebGL 而失败，已按现有两张人物素材及独立场景契约调整。发束初版互补 Alpha 以 source-over 合成有暗缝，改为互补合成并实际重绘。另核对 320/390/430/780/853 像素宽度，修正分块缩放造成的躯干细缝；现在仅重绘发束局部，再将完整人物统一缩放，五档宽度的固定身体像素变化均为 0。

`preview/atmosphere/build.mjs` 从生产模块构建自包含验收页，示例列表不读写真实数据。当前容器缺少可用浏览器，本轮没有完整浏览器布局或 Android 实机证据，也没有真实模型调用。需在目标设备检查字体、页面切换、雨雪流畅度和点触音量。原宿主脚本 iframe 的事件边界保持原样，此次不扩大卡片脚本权限。
