# 简表与完整注入参考交付

本候选承接已保存的 UI／世界书草稿修复 bb1467c273d70d717e6887665e69057df0c08467。正式 main 未在本阶段更新。

## 本阶段已实现

- 全部 11 个 TABLE 任务使用简表文本；规则校对保留其专用简表，其他任务使用共享递归子表。初始化改名、世界／计划两种输出、单／组基点、创世和原生配置变体均有实际提示词与解析入口。
- 10 个 TEXT 任务的资料输入展开为简表；原本应返回正文的任务继续返回正文。宿主、自定义执行器、重骰、用户改写、场外要求及档案工具边界同步迁移。工具供应商封套保留 JSON，但本插件业务参数只有一个 sheet 字符串。
- Foundation 复杂格使用子表，支持多行、类型和授权引用；不把嵌套对象藏在 JSON 文本格内。
- 主回复固定列使用 `format="pipes" text="escaped"`；文字分隔符和换行显式转义，复杂值引用本块末尾简表。旧消息保持原语义，原卡 extra／vars／JSONPatch 等外部协议仍由原卡拥有。
- 正文资料使用 user、关注人物、在场其他人物、当前叙事待办、静态图鉴、当前快照、历史事件等自然分区。字段条件、名称引用、知情范围和实际原生值保留；未激活或被条件排除的原生引用不再经全量快照绕回正文。
- 偏好分析只发送完整偏好表的注册定义，不发送无关的其他表和类型。注册材料由 32,551 字符减到 3,166 字符（90.27%），不是 token 或延迟测量。通用简表本身未证明比紧凑 JSON 更省 token。
- 基点证据按授权字段的原始文本叶连续匹配，保留换行、引号和反斜线；不跨字段拼接证据，不把 ID／版本／权限元数据当剧情证据。

## 验证

统一 `npm test`：13 个生成检查及 1362／1362 项通过。其后偏好注册材料裁剪的针对性 12 项通过；最终 extension 已重建并通过一致性检查。原始首次／中间失败日志保留，没有以删除断言取得通过。修复阶段和本阶段均未在用户 Android 上实测。

隔离助手模拟只读取实际编译的偏好预设、任务和合成来源。第一份输出存在会话列表类型错误，被原校验器拒绝；另一次工具读取截断后模型返回待处理，无写入，不能计入完整输入验收。补清类型说明并完整读取 3282 行后，输出通过简表解析及原 prepareCommit，产生一项仅当前会话的偏好候选，未写入真实存档。这不是所有任务真实外部 API 成功率证明。

源码生成器 `tools/export-full-preset-reference.mjs` 生成完整 TXT；它包含实际主请求、可选条目、全部 TABLE／TEXT 预设、字段与条件占位符，并将未接线目标明确分开。占位内容不是用户真实角色卡或手机请求快照。

## 明确保留的边界

内部持久化、HTTP、历史读取、哈希与版本校验仍用 JSON；原文里已经存在的 JSON／脚本作为来源原样保留。自定义 JS executor 可读取新的 typedInput；自行硬编码 JSON.parse(input) 的外部执行器需要采用该新接口。

生成前联合归档＋世界推演＋档案调取 A，再正文＋当轮偏好 B 的调度尚未接线；当前仍按实际任务分别触发请求。逐条原世界书替代、触发与位置映射，以及只裁掉已经可靠归档的长历史，也仍属于 TXT 中的设计稿。本阶段没有把这些目标写成已完成功能。

本候选不自动改写用户原书，不清除现有角色、变量或存档，也未发起付费外部 API 试验。
