# RP01 · char 主动性

用户请求更新配置，改善人物等待玩家逐步授权、要求玩家提供剧情大纲的 RP 体验。现有“角色自主”已允许人物自己的目标，但授权与既成事实的笼统措辞可能被模型过度理解；没有该次完整请求与模型对照，不能认定这是实际根因。

## 配置与行为

- 入口：配置 → 本模式配置 → char 主动性。
- 可选“沿用原设置”“自主互动”“主动推进”。推荐想体验人物自主行动的玩家选“主动推进”；不自动更改任何已有世界的设置。
- 自主互动：人物主动表达、提议、拒绝及作出当下的小动作，推进眼前交往。
- 主动推进：人物还可依据自己的目标、已有事务与当前机会采取行动，形成玩家可以回应的新局面。不要求玩家先写大纲或逐项批准 NPC 行动。
- 均保留玩家代写、重大选择、心理代写、回合停点、视角、知识、能力及时间边界。人物的提议不等于玩家同意；不自动完成共同活动或改变双方关系；不强制每轮制造冲突或惊喜。只把本轮确实展开的行为与后果记为发生。

## 数据与适用范围

可选中文字段 `缇斯亚配置.worlds[世界键].modes.narrative.角色主动性`，枚举为 `自主互动`、`主动推进`。缺失表示沿用既有行为；读取不回填，恢复“沿用原设置”删除该字段。无效值明确拒绝，配置备份沿用原数据通道。

只影响配套模块化预设的“互动叙事”，要求“角色自主”“人物反应”“行动与剧情”启用，预设内部流程实际参与编译。关闭依赖时保留选择并提示，不自动开启。大纲扩写、场外讨论、总结整理及其他任务不引入新剧情。完整、精简、仅格式与配置均采用同一档位规则，替换现有角色自主规则，不叠加第二套独立开关。不改 vendor 原稿或来源散列，不增加 API 请求。

## 验收范围

核对 UI 保存/重开/分支隔离/导入导出、旧配置不变、无效值拒绝、关闭依赖与非互动任务旁路、三种流程和普通/结构化正文中的实际组装结果。实际模型能否持续表现出主动性以及 Android 操作仍需用户试用；本地编译通过不代表 RP 效果已证实。AT04 断流原因、完整正文工具包装与真实工具/搜索组合不在本次修复范围。
