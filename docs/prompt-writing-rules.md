# 提示词书写铁律

2026-10-28 用户明确修订，适用于本项目后续新增与改写的提示词。

1. 先给精准、直接、可执行的正向要求。正向要求已经充分表达目标时，删除同义负向补充。
2. 必须存在的禁令集中前置，使用“禁止……”或“PROHIBITED: …”。必要例子：禁止神化玩家；禁止将角色片面、极端化塑造；禁止泄露未公开秘密。
3. 删除软化表达和反复叠甲。每条保留的禁令须保护一个独立且必要的边界；已有唯一消费者的边界由原位置执行。
4. 词义直白。欲望凝视明确观看主体、被看对象、吸引点以及怎样勾起观看者的欲望；用具体感官与互动组织性张力。
5. 审美、欲望位置、凝视方向分别表达。男凝/女凝与谁凝视谁可组合；人物审美分其他角色与user；体位倾向提供user的气质方向，明确审美优先。

验证：新卡正文检查重复的边界段、软回避和同义负向；保留禁令检查必要性、前置及唯一归属。语义与模型实际效果另验。
