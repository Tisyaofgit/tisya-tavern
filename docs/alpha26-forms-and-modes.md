# alpha26 · 可视化表单、配套模式与资料槽

版本说明：alpha27 已将辅助任务改为直接 JSON，不再沿用本文的十块回复包装；当前用法见 [alpha27](alpha27-auxiliary-and-native.md)。

本版修复设置页给 `textarea.type` 赋值导致中断的问题。输入控件只对 `input` 设置 type，文本区保持自身类型。原有数据不会因升级被重建。

## 使用入口

配置 → 表单推进：

- **当前表单**：逐字段新建、编辑。支持数值、布尔、枚举、关联对象、多项列表、嵌套属性和明确空值；“未提供”与 null 分开。人工修改会保存来源和时间锚，并锁定修改字段，防止自动归档覆盖。
- **历史补录**：扫描实际楼层，按范围分批补录；也可粘贴手写历史或导入日志，查看表单草稿后保存。没有 memory 块不阻断聊天或补录。默认仍排除最新 AI 候选。
- **创世与模板**：创建或编辑表格、类型、字段、枚举、别名和公式。现有字段不直接更换类型，新字段保持兼容。公式通过受限操作和参数表单编辑，不执行 JavaScript。
- **偏好确认**：分析只生成候选。可改、选中接受或拒绝。确认后才进入正文上下文；重投或修改来源会使旧候选失效。升级前自动产生的偏好标为旧记录，重新确认前不注入。停用某项可编辑“启用”为否。
- **禁词与文风**：原预设 F.10 的 7 个词句、6 个正则，以及 F.09/F.11 的写作要求集中管理；可增删、修改、恢复内置规则。启用规则作为硬约束注入，也能检查一段正文。检查不会自动删除原文，正则不能保证发现所有语义套话。

禁词／明确规则与表单推进开关独立。关闭表单不调用归档 API，不要求建立世界书；原生历史条数仍独立生效。已确认偏好依赖相应会话存档及偏好开关。

## 创世应用边界

创世 API 交付既有接口规定的 blueprint、checklist、artifacts、workflow。蓝图、决定、未定事项、核对清单、原点档案、开局初值及工作流都能先编辑。

确认保存后：

1. 表格和类型登记在原点书，共享给本卡可复用档案。
2. 对象和常量事实写为原点版本。
3. 场景、状态、关系、持有、任务、日程、线索及新增业务表初值写进本会话。
4. 关联字段将临时对象编号转成稳定编号；所有修改产生时间锚。

工作流保存为蓝图设计依据；不会自动执行任意工作流步骤。自动归档、剧情推进、偏好和独立建档仍由各自开关运行。原点／会话跨书写入无法做到服务端事务；后一步失败会报告，未绑定候选不作为当前进度。

## 辅助 API 与预设

归档、剧情推进、偏好确认、创世设计、新发现建档和历史补录均已注册为模式。默认继承实际主 API 连接、模型，使用内置 `tisya:任务ID` 配套预设；在“预设与 API”可独立覆盖。配套预设运行时编译，不需要另外导入六份文件。

共用缇斯亚身份、心声表情和 reply 十块结构。切换内部任务流程、当前来源和资料槽；工作报告默认 80–600 字，模式配置中可改。机器产物固定放在 `extra/tisya_result`，经过证据、类型、版本、职责和关联校验才填表。外部变量指令继续归入 `vars`，由原卡变量框架执行；表单不成为第二个原生变量写入器。旧辅助服务直接返回 JSON 的结果仍可读，但配套预设要求共用 reply 格式。

旧 `memory`、`table`、`genesis` 请求别名接到对应归档／创世服务，旧 API 路由引用保留；配置不再重复列出这些别名。侧栏移除了第二个同目的“模式与聊天设置”入口；快捷栏自定义不变。

## 固定资料槽

| 资料 | 配套预设槽 | 使用限制 |
|---|---|---|
| 当前来源 | current_input | 来源快照，仅本次任务 |
| 记忆记录 | memory_archive | 已有事件与暂存来源分明 |
| 当前表单 | current_state | 当前版本、事实与到期检查 |
| 偏好与禁词 | rule_material | 明确规则、已确认且启用偏好 |
| 剧情方案 | task_analysis | 条件提案，不是已发生事实 |
| 创世蓝图 | task_material | 已应用蓝图及未定事项 |
| 工具定义 | tool_prompt | 本次明确提供的工具用法 |
| 工具调用 | tool_calls | 实际调用记录 |
| 工具结果 | tool_result | 来源回执，工具声称不等于核实 |

这些槽接入 TASK.START 原有预处理器，保留来源、权限、时间和版本；空槽不造内容。工具槽是注入接口，本版没有自动授权或执行新增工具。原生模式由宿主通过扩展提示与原生世界书扫描装配，本扩展不改写最终原生请求；手选资料模式把内容放进对应材料槽。缺少新增空槽的旧预设，在资料层结束前放入同名分区，避免丢内容。

默认蓝绿灯机制保留：档案按名称／别名／关联字段命中，上回合标签提高本轮可见性，受宿主预算约束；完整账本始终禁止自动注入。明确规则、已确认偏好与剧情设计独立成槽，不重复混入档案条目。
