# alpha31.1 初始化与导航修复

本次没有调整正文格式、角色卡设定、表格字段或原生脚本协议。

## 修复

此前 `GENERATION_STOPPED`、`GENERATION_ENDED` 等主聊天事件会直接调用表单服务的全局清理方法，取消正在等待返回的手动初始化。已用旧版事件处理器复现：初始化 HTTP 请求在无关停止事件后收到中止信号。

现在区分手动任务与聊天附属任务。主聊天只停止自己的推进任务；界面的停止按钮停止当前手动任务。实际换会话会停止旧任务，保存前仍检查会话、聊天内容和配置版本。同一会话的刷新通知不会关闭配置页。

初始化按钮遵循“初始化来源”。复用模板与通用空表不再意外调用角色卡分析 API。初始化预览纳入未保存草稿保护，可保存或放弃；停止后可重新开始。若中止来自宿主或 API，界面说明来源未知并提示检查连接，不自动重发请求。

配置分类、十二个表单功能和十六张当前表格均用下拉菜单选择。表格编辑后切换菜单会要求保存或放弃；操作结束不再残留“正在处理”提示。

## 验证

- 程序回归：366 项通过，包含欢迎页启动、聊天切换、主聊天停止与手动任务隔离、失败重试、草稿保护和初始化来源选择。
- 生产界面 → 服务 → 请求组装 → HTTP 返回 → 原点／存档写入：从界面点击初始化完成，保存记录可在“当前表单”打开。
- Chromium 回放三张原始角色卡与上一轮隔离模型结果，分别得到 101、222、21 条记录。每卡十次功能／表格菜单往返后数量不变、无重复书籍、无页面脚本错误。
- 390、430、1024 像素宽度检查：导航不再平铺按钮，中文字体下无横向溢出。
- 使用官方 TauriTavern 请求与中止实现、酒馆助手世界书绑定实现核对接口。本次没有修改这些外部实现。

上述浏览器测试使用受控本地 HTTP 和此前保存的模型返回，不是新的线上模型十轮测试，也不替代 Android 实机验证。截图中的英文错误没有附带手机日志，不能仅凭截图排除提供商主动中止等其他来源；这次确认并修复了可复现的插件误取消路径，并补足其他中止来源的提示。
