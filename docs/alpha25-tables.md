# alpha25 · 表单推进与辅助 API

本版新增独立的“表单推进”配置页，默认关闭。旧记忆接管不会恢复；历史条数仍独立生效，数据库／原生和手选资料都可用。表单启用时，最新 AI 回复另作暂存接续资料注入。

## 开始使用

1. 打开一个角色卡会话，在配置 → 表单推进 → 设置与绑定，创建／绑定世界书。
2. 原点书自动复用这张角色卡已有的缇斯亚原点书，也可填入要复用的书名；原有角色书、数据库书绑定保留。会话存档另建，不占用数据库插件的聊天世界书绑定。
3. 旧会话先打开“历史补录”：自动扫描楼层，选择起止楼层与本批最多 AI 回复数，从早到晚补录。默认不归档最新 AI 层。已完成的楼层自动跳过，可停止、续跑；有错误会显示原因，不标作完成。
4. 如有聊天记录以外的往事，粘贴手写摘要或导入文本，生成草稿，修改后确认写入。原文和已知剧情时间保留，未知时间不猜。同一份原文禁止重复入账。
5. 在“创世与模板”生成基础档案草稿；使用当前卡的描述、性格、场景与填写的创世要求。保存后写入角色卡原点书。新会话可勾选复用的原点版本。
6. 保存“启用表单推进”。归档、剧情推进、偏好分析、新发现独立建档分别开关；默认偏好分析关闭。各辅助任务在“预设与 API”选择连接和模型。默认继承实际主聊天连接与模型，使用独立任务指令，不默认带叙事预设。

## 表单及职责

基础有 12 张业务表：常量档案、事实与发现、场景与全局进度、对象当前状态、关系、认知与心理、持有与流转、任务待办、日程倒计时、伏笔线索、历史事件记忆、用户叙事偏好。模板注册、消息来源与版本、变化时间锚由程序维护。

- 已有 memory 块的事件摘要原样保存；辅助 API 填其他表。没有 memory 的旧消息可以通过历史补录生成事件记录，不要求改写历史消息。
- 当前表单可新建和编辑。人工修改字段会锁定，自动修改碰到锁定字段会停止该提交并说明冲突，不覆盖人工修订。
- 模板支持增加字段、别名和专用表。现有字段类型不能静默改动。自动新增对象类型必须扩展已有模板；同名／别名冲突不入库。近义词的语义识别仍依赖模型判断，不能保证完全无重复分类。
- 原点档案保留各版本，会话引用特定版本。切换会话不会自动采用其他会话的新版本；新发现先形成当前会话采用的版本，未采用的候选不会注入。
- 每项字段变化带来源、前后值、记录时间和已知剧情时间。时间未知保留未知。重投、编辑、删除消息会按来源链重新计算当前视图，不把被舍弃候选当事实。
- 主体知情与读者权限分别存储；关联和公式不增加人物知识。公式仅支持受限 AST 的字段、查询、计数、去重、拼接和加减，不执行 JavaScript。
- 剧情推进 API 只产生计划、待定选择和触发条件，不直接写事实表。倒计时到期仅表示检查条件，不自动完成事件。
- 偏好 API 只分析有用户输入依据的叙事偏好，区分明确要求与推测；单纯重投不推断原因。明确规则、禁用词及防八股设置进入正文上下文。

## 检索与主请求

默认使用酒馆原生蓝绿灯：当前场景、已启用偏好、到期检查为蓝灯；人物、物品、地点、事件及关联状态为绿灯，使用名称、别名、标签和关联对象名称匹配。上一条回复标注的名称及其直接关联临时升为蓝灯一轮；向量命中也升为本轮蓝灯。

这只是激活方式，不保证一定装入：蓝绿灯都受原生世界书 token 预算和扫描设置约束。关闭递归激活，避免命中一个名字展开整本书。上回合暂存优先采用原有 memory，缺少时采用正文或原消息，作为本轮蓝灯接续资料；完整版本账本始终禁用。控制规则与剧情设计单独注入。

生成时向 `WORLDINFO_ENTRIES_LOADED` 的聊天条目列表追加只读投影，保留其他插件条目，不修改世界书原文，不占用聊天世界书绑定。原生模式由宿主完成插入；手选资料模式只接入 `WORLD_INFO_ACTIVATED` 确认的本模块条目，不转入其他未选世界书。当前表单页显示最近一轮的激活条目、原因、灯色和字符数（字符数不是 token 测量）。

不支持扫描事件的旧宿主可手动选“直接组装”，不会暗中切换。原始聊天不修改，最终原生请求不重写；角色卡变量仍由原卡 MVU 执行。

结构化回复可用 `引用：名称、名称` 和 `新发现：对象或事实|类型|名称|依据`。普通卡不强制新增 reply 包装。新增标签已接入阅读解析器。

关键词检索是默认方式；可选原生向量 API。向量使用独立会话索引，随来源版本更新和删除失效键，只接受仍存在于当前表中的命中；嵌入与凭据由原生向量提供商管理，不写进世界书。当前适配 transformers、OpenAI、Cohere、Together、Nomic、Mistral、ElectronHub、OpenRouter、Chutes、NanoGPT 的原生路由。选定向量后接口失败会报错，不暗中改用关键词。

## 依赖与验证边界

世界书读写需要新版酒馆助手公开的 Worldbook API；本扩展不内置该插件，也不调用其变量写入接口。当前自动建书入口面向单角色卡会话。

本版验证覆盖本地测试、模拟宿主世界书持久化、API 路由／产物校验、界面和生成入口。尚未使用用户真实 API、真实 Android 设备及其数据库插件组合验收；不能把模拟接口通过当作真实服务商调用成功。

辅助失败不删除正文或旧档案；自动流程会停止并显示错误。可以关闭表单推进继续用原生／数据库。原点与会话书是两个存储对象，跨书保存不能保证原子性；若原点成功而会话失败，会明确报告，未绑定的原点候选不会注入。
