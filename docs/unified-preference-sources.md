# 世界书、文风与条件的统一采用路径

在配置的“资料与文风库”读取一本世界书，查看条目全文，选择文风或技法用途，预览完整目标位置，再加入当前故事草稿并保存。世界书已保存条目的“在资料与文风库中查看／采用”进入同一页面。原生批量编辑、关键词、向量、常驻和原始扩展元数据仍由原世界书编辑器管理。

原文始终留在原书及原 UID。当前故事的采用原文保存在既有 `T_PREF_SELECTION_OPTIONS.effect_directive`，唯一新增关系字段 `source_route_ref` 指向 `T_SYS_SOURCE_ROUTES`。路由记录书名、UID、原生条目的完整规范 JSON SHA-256 和目标槽。指纹是派生回执：正式保存服务重新读原条目并匹配，普通手工输入不能替代读取证据。原书没有被写入，未增加第二套内容数据库。

此页明确选择的是偏好消费者：原生停用、关键词、向量、原生粘性或延时不控制这个位置。已有外部条件继续有效；偏好条目以“来源＋目标位置”作为机会身份，加入同一世界书条件批次，复用现有概率、冷却、限次与版本守卫。预览只读，条件满足但尚未抽签时只展示命中时可能采用的内容。条件假、未知或未命中不注入；缺少当前轮判定、版本变化、来源变更或迟到结果会阻止发送。

已明确采用的条目从本轮原生扫描副本移除，避免原生和偏好重复发送；原生数据不变。不同导航重复选择同来源同目标位置会被拦住，同文不同身份不会被按文本误合并。多选组包含来源引用时逐条编辑；整组覆盖暂不支持，以免覆盖文绕过个别来源条件。跨故事默认不接受当前故事路由；偏好包导出保留文本副本，导入后仍须明确采用。

原书正文或元数据改变后，不会静默换成新版本。统一页面并列显示原书全文和故事采用全文，可以明确采用新版，也可以保留故事改写并确认新版来源。来源被删除或重命名时按原身份报错，不猜测同名或同文替代项。

现有条件可从条目进入同一表单编辑器；世界书原编辑器继续提供规则选择及版本确认。本次未新增复杂条件的可视化搭建器。自动化验证覆盖真实保存服务、DOM 按钮、冷重开与最终请求，以及原宿主扫描函数夹具；这些不能替代真实浏览器、宿主、模型或 Android 验收。
