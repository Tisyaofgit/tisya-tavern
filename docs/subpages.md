# 子页与唯一入口 · alpha31.26

角色页和详情使用真实角色卡图片、已保存会话及原有显示名/分组/置顶数据；列表支持搜索，箭头或长按展开原行菜单。聊天行保持完整文件身份，角色列表变化时拒绝用旧编号切换。

群聊拥有独立目录，点行调用宿主 openGroupChat(groupId, chatId)；箭头展开管理按钮，资料和成员直接进入 select_group_chats(groupId, false)，不为编辑先加载聊天。创建调用宿主原有建群面板。原角色创建、文件/网址导入、批量管理统一从角色页底部进入原编辑器；不新增第二套数据。

设置按创作、显示、聊天、系统四组整理；21个常规目标，宿主支持全屏时增加该唯一目标。未知第三方抽屉动态发现。主页的五个管理入口不复制进设置。缓存只有“聊天显示与缓存”一个设置入口，主题页不再复制缓存操作。会话手记/公开记忆是同一记录页的两个栏目。消息及长按操作仍在其对象上下文内，原生聊天菜单保留在输入区。

用户资料、世界书、预设、连接、背景、系统和扩展保留宿主完整编辑器，仅改变内容外观；不搬动原控件、不修改其事件或面板几何。角色原编辑器仍沿宿主 selectCharacterById，需载入角色当前聊天；本版没有接管完整聊天读取缓存，不承诺消除宿主所有读取时间。

修正手机“协议”到原生输出格式入口。原生API编辑器不再被自身按钮的忙碌状态误拦；未保存配置和显示条数在页面/手机导航时会阻止离开，要求先保存或放弃。

完整功能归属见 entry-capabilities.json：45组能力。原始核对来自 TauriTavern a1855be4a4f8b6ee7cd0374a84dbb3709c3e5375 与真实APK提取HTML，9个抽屉、906个静态控件；静态清单不是第三方运行时功能穷举，也不是906个独立功能。

验证：源代码回归及真实构建浏览器测试记录见同版本验证文件。浏览器为隔离宿主接口/数据夹具；原生DOM检查使用APK原HTML和宿主CSS；不等同Android实测或后台保存/模型验收。
