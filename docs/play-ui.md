## 默认语言与对白

默认语言沿用 `缇斯亚叙事语言` 和 `缇斯亚叙事语言配置`，可选简中、繁中或填写其他语言。模式新增可选 `角色对白 = {启用, 来源, 语言}`；未设置时旧行为原样保留。新开启双语默认跟随已知角色母语/场景，也可指定原语；旁白与译文使用默认语言。不同语言对白原文后接译文，单次发言，同语不重复。保留情话、咒语、称呼语感；不凭姓名或族裔猜测母语，不新增角色语言能力或知情。

旧版“双语对白”打开无写入；明确修改语言区后，界面说明第二语言作为默认语言、第一语言作为指定对白原语，可调整再保存。空语言名称阻止保存，不拿猜测补齐。关闭双语保留已填语言和默认语言。当前分支保存，导入导出使用同一配置源。

编译时正文组织、输出 JSON 与语言规则不再重复全文；C.2 的 @LANG 持有规则，@OUT 只引用。三种工作流详略均在完整实际请求中验证。使用缇斯亚配套预设生效，界面设置不承诺所有模型完美服从。
