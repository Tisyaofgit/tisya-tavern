# alpha31.30 档案生命周期

本版将条件引擎、世界数值注册、档案提炼、图鉴与分层世界书接入 alpha31.29 的角色／群聊和统一设置。

## 从角色卡建立存档

1. 选择角色卡与原生 user 人设，在「表单推进 → 初始化与历史」按材料建立初始表单。
2. 核对并保存。原点书绑定当前角色卡，user 原文成为明确绑定的人物档案；会话初值进入独立存档。
3. 之后同卡、同定义、同 user 的新会话自动复用固定开局版本。不复制上一局的事件、成长、任务完成或临时状态。修改角色卡或 user 定义后，需要重新核对初始化。
4. 在「设置与绑定」查看各环节状态，在「用户身份」预览并确认已有档案与原生 user 的绑定。
5. 启用表单推进及自动归档后，按已确认回复更新当前表单。最新未确认候选保留为上下文；重投／修改来源后，依赖旧来源的投影失效。也可在历史页手动补录。

基点按选中的对象、核心意义、关联及成长提取，再适配为当前世界原点；不会因为对象名称相同而自动合并身份。

## 保存、恢复与查看

「平行存档」支持独立时间锚、冻结原著、完整存档导出和预览恢复。恢复只接受同原点的空会话，或尚未推进的自动开局；预览后发生其他修改会阻止写入。时间锚进入新分支，未来蓝本不作为已发生事实。

「图鉴 · 最新存档」默认显示当前版本，可切换原点，点击对象关联与子项。静态档案、数值、动态快照和记忆在同一存档世界书中生成分层阅读条目，修改保留来源、时间锚及字段路径。AI 接收按权限与预算组装的同源投影；完整账本和秘密不作为整书恒定注入。

## 条件与数值

世界注册表统一状态、等级名称、公式与成长条件。条件引擎连接世界书条目门禁，保留宿主的排序、预算与作用域。概率结果及已执行事件有回执，重载和重投不应重复奖励。世界书前缀只识别材料类别；普通叙事仍须提炼校验后入档。

## 验证范围

本地自动测试和浏览器模拟宿主覆盖初始化、跨会话隔离、恢复、分支、条件、世界书、图鉴与原版角色／群聊功能。实际模型输出语义、Android 宿主与第三方扩展组合需另行实测；本次未调用真实模型，未改写用户真实档案。
