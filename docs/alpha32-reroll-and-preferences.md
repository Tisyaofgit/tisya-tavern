# 重骰与偏好候选 · alpha32 候选补充

重骰入口先让玩家选择全文或局部修改、勾选段落并填写方向。旧版本保留在宿主原生 swipes 中；消息下的 n/N 与左右按钮只切换已存在版本，不触发生成。较早楼层先通过宿主建立独立分支，原聊天的后文保留。分支复制可按来源选择的提交记录，不把待替换候选的结果冻结成始终有效的事实。

段落标记绑定聊天、消息、候选及完整正文。关闭后重开保留本版本的会话内草稿；换版本不会套用旧标记。局部生成在宿主完成后检查段数及未选段落原文；越界则退回旧候选并保留失败候选，表单归档不接受该次结果。宿主负责切换候选正文与附属数据。原生 MVU 与 Android 的实际事件顺序、停止和候选切换仍需设备验收。

本次修改方向默认不成为长期偏好。勾选“另提长期偏好候选”后才送对应专用预设；候选在偏好确认页可编辑、确认或拒绝。确认前不影响正文。重骰反馈独立于被拒绝的故事候选保存；没有理由的重骰不能推断偏好原因，切换版本不计为重骰。

用户叙事偏好按用词、SFW角色表现、剧情走向、文风、特定情节及虚构NSFW题材分行。倾向区间允许多条独立维度，每条填写左端、右端、−100～100内的下限和上限及原话依据。未知值省略，不默认为0。用户给出的数值原样保留；定性语言只能产生明确标为建议、等待调整的候选。区间和标签均可在确认前修改。

验证边界：程序回归、隔离模型首稿、实际宿主与设备验收分别记账。中性重骰样本不算原100楼回放，也不算原卡连续10轮叙事。原卡、世界书和原记录语料均保留。
