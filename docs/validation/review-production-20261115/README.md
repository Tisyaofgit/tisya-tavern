# 每轮确认与历史补录正式接入

版本：0.2.0-alpha.31.31.19-onepass.16-candidate.35-memory.2。基线为 54f446b，现有公开 main 为 2cddecbb73bac4fb2e9b94a7eba9e6c6eacded36。用户本轮明确允许发布。未纳入第三方包源码、附件中的故事记忆、真实用户存档或独立图鉴工作区。

## 接入与归属

- `turn_review.settings` 是常驻自定义定义、显示名与每轮核对政策的配置归属；运行 schema 从它投影，不另存一份可编辑配置。历史补录政策独立保存在当前补录批次。
- 每轮 cells 与 archive 候选编辑不执行；确认通过共同校验与同一次 CAS 写入。未更新的必填字段需明确核对，响应保留在确认回执。源码或前序确认变化使旧候选失效。
- 补录通过已有简表解析器提炼，保留原答及解析错误，可手改重新解析。每层先保存候选，再由明确确认写入规范历史事实；不调用当前资源结算器。两个渠道引用同一历史事实，内部引用转为可读名称。
- 补录事实进入原有 journal/manual edit 回退路径，按实际来源楼层与内容校验。当前正文删除、改写或回退时，离开的事实不会继续作为有效投影；没有另建影子历史数据库。
- 原有表单页在生产接线中转入同一确认工作区；原叙事建档工具继续承担人物／世界档案创建。
- 主聊天的原生 history 副本被三层历史替换，原始聊天不修改。所选窗口外 user 不注入；近期只取 body／boby 并去合法段号；最新 char 保留完整原文。覆盖需要已确认的来源关系，独立事实不按关键词模糊删除。
- 机械字段仍由既有模型边界过滤。模型未被要求抄内部 ID、指纹、来源字段或事务回执；新键名在注册界面完成登记，正常回合只使用字段显示名。
