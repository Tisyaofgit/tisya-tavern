It confirms source/reference and settings, does not select the new slot, and preserves old personas and defaults. A lost acknowledgement or interrupted native initialization resumes the same reserved matching slot. A failed new slot does not quarantine unrelated existing identities/chat.

Default avatar upload is verified by listing the returned ID. No new named host export is assumed at module loading; action-time capability checks remain visible.
- world-seed.js works before a card or chat exists. It persists the idea, creates a separate blank carrier using the existing character host, marks it with a stable creator_notes token and opens its chat. A lost create response searches that marker and does not blindly create another card. Existing worlds/cards/history are retained.
