## 实际改变

- 插件启动通过原生预设选择和载入回执切换到Tisya。当前连接、模型、采样参数保留；已保存的同版本预设手改只载入，不自动覆盖。
- 打开或切回聊天时，绑定并启用新版Matrix引擎。没有聊天时零建库；首次接入只把既有消息记为历史基线。已有数据、角色绑定和分支保留；已知绑定丢档/损坏明确报错，拒绝空白重置。中断的首次写入只按明确pending标记续完。
- 同一聊天内手动停用不会被生成准备重新打开；重新打开聊天按默认启用。用户主动换到其他预设后使用宿主原生生成流程。

- 新页仍提供原点精确预览、确认绑定、失败恢复、独立人物槽位、身份应用范围、草稿历史与导出。所有修改使用同一底部保存/取消；局部失败沿原回执续完，不重复建档或创建槽位。
- 创作同时保留显式基点来源与实际原生卡/关联书/用户人设/模板快照；生成后及保存前重读核验，漂移拒写并保留原始回答和草稿。群聊没有指定单个角色时保留空角色来源，不自动挑群成员。

## 原始失败与边界

`full-suite-first.log`、`full-suite-first-result.json`保留首轮1932通过/1失败：旧源码断言仍要求已退休的主链路，现已改为验证Matrix入口、模板书排除、终止事件及旧调用缺席。其余独立世界书条件服务测试保留。

`shell/`保留旧入口预期、异步fixture、IndexedDB属性和不完整运行的原日志。修复测试窗口销毁及短断言后，最终100项正常退出；没有调高产品或测试堆上限。来源专项保留派生base_year样本被正确拒绝和模拟人设同步不足的原失败；测试样本修正后通过，没有放宽产品保护。

共享浏览器访问本地HTTP得到ERR_CONNECTION_REFUSED，后续观察被URL安全策略拒绝，已停止该路径，详见 `browser-boundary.json`。本轮没有真实宿主安装、外部模型调用、浏览器像素/滚动或Android实测。所有写入测试使用隔离内存/IndexedDB和合成样本；未访问或重置用户运行存档。
