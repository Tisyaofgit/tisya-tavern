## 已确认的缺口与修复

旧 V3 只提供辅助预设查看／导出，运行时固定使用内嵌预设；现已接通命名辅助预设的实际装配、参数与独立任务路由，保留动态资料和完整简表协议。

旧 queryCatalog 只有四个方法名；现从既有档案查询定义注入完整参数 schema。档案查询由 archiveRequests 驱动，普通 A/B 不启用原生函数工具。

旧 V3 请求绕过配置的抗截断入口；现按任务配置接入。文字传输可能使用一个包装函数。原生 TT 中助手扩展的角色导出监听会包裹 fetch，原来的严格顶层函数身份检查误判冲突；受控 V3 请求允许外层包装，但要求同一传输所有者、精确请求匹配和完成回执。绕开处理的响应被拒绝。

旧正文共用辅助 API 的错误文案；现按实际阶段标记。SAFETY/content_filter、长度限制、坏 JSON、意外工具结束保留不同失败。格式检查不推断或伪造服务商过滤原因。
