# 世界总框架与共享条件 · candidate.36-world.1

## 变更

世界总框架是原有规范表的组织和编辑入口：T_STATIC_WORLDS 为根，历法仍归 M_CALENDAR_*，地点归 T_STATIC_PLACES/PLACE_LINKS，币种归 T_STATIC_ITEMS_SKILLS，度量与换算归 M_UNITS/M_UNIT_RATIOS。没有增加第二份公共事实账本。钱包、事件、对象和时间记录继续使用原外键；当前时刻、位置与余额不放进固定定义。

公共定义进入世界资料槽时只展开一次。其余模块保留可读引用。多世界不猜测无归属旧记录的世界；明确的作用域、字段可见性和旧资料仍按既有合同处理。新建定义的作用域元数据复用原稳定记录，不重复登记。

条件编辑原先写旧 origin/session 规则，而主生成扫描读取 Matrix。现在两者注入同一 conditionService。极简编辑只填写名称、原字段、比较、值/另一字段；全部/任一条件组及可选失效组复用 M_CONDITIONS 和 M_FIELD_REFERENCES。程序生成内部身份，世界书条目引用同一个门禁，模型不接收条件执行代码。概率、冷却、次数及回合窗口继续复用既有机会回执。来源变更、过期修订、未知值、非公开依赖按原守卫拒绝；含扩展观察/说明的旧条件保留原定义，不静默扁平化。

借鉴角色卡世界书以路线、年份范围和人物阶段选择资料的思路；重点参考背景控制与人物阶段控制。没有执行附件脚本、引入 EJS 引擎、复制人物设定或导入其业务数据。
