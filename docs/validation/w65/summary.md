# Current skeleton, classified preferences

Scope: keep the current One-Pass eleven-block envelope and existing state/archive consumers. The supplied V3 text is an organizational reference for UserPreferences; it does not switch the runtime to V3 preflight, six-block delivery or another storage scheme.

Selected writing controls have one owner:

| Location | Controls |
| --- | --- |
| GlobalWritingRequirements | Player speech/action/interiority authority, major choices, disclosure, output/dialogue language, enabled public-digest detail and configured hard constraints |
| NarrativeComposition | Input handling, stopping point, authoring mode, person/viewpoint, psychology and sideplots, planning/stage/detail selection |
| CharacterPortrayal | Cast scope, emotional expression, complete selected initiative with player boundaries, enabled character checks |
| PlotPreferences | Tone, pace, pressure, difficulty, centrality, enabled resilience guidance |
| SpeechHabits | Configured aside voice and optional user catchphrase preservation |
| DictionAndStyle | Dialogue proportion, diction, description focus, optional narrative-voice continuation and enabled prose checks |
| ProhibitedWordsAndPatterns | Effective wording bans and explicit world boundary |
| StyleResources / selected materials | Built-in style or actual selected resource bodies, parameterized once; unselected resources stay absent |
| Existing REGISTRY | Actual body/action ranges, enabled asides in both phases, summary/action/output switches and unchanged machine contracts |

The registry references the preference-owned digest/aside wording. Complete initiative is defined once in CharacterPortrayal; the creative stages consume it without duplicating another rule. Turning off an optional check does not revoke mandatory identity, source, player authority or disclosure constraints.

Fixed mismatches:

- Missing heartDirections used to look like three directions in the UI but compile as no comments. UI, bridge, compiler and mood selection now share the same read default; explicit [] remains off, without writing defaults.
- Full/compact/format now produce different creative-guide detail. Missing workflow detail uses the same compact default as the UI.
- The authoring selector accepts discussion and organization as well as interaction/outline. Out-of-story tasks keep the current envelope, use the body for the requested work, and cannot invent story progression or archival changes to fill auxiliary fields.
- Both live macros and both main send paths skip mood access when asides or structured output are off.
- Native context previously omitted explicitly configured style/requirement resources and selected player/focus identity material. These now enter the existing material boundary without replacing native history, card data or tools. Main versus supplementary style roles remain labeled, supplements retain the configured base style, and identical bodies are deduplicated with main-style priority. Changed resource sources, stale selections and ambiguous boundaries fail visibly. Controlled One-Pass no longer repeats a boundary already owned by UserPreferences.
- The legacy narrative bridge remains an effective read view for modular presets; its obsolete writer refuses to claim success and identifies the canonical configuration page. No legacy variables, global preferences or player records are migrated/reset.

Validation includes every supported wording option and editable rule, all stage toggles, optional feature owners, languages, length/action ranges, all heart masks with summary on/off, global save/reopen/card switch, real configuration checkboxes, and native/controlled settings-ready adapter requests. Resource inclusion, exclusion, source-change rejection, selected identity material and unchanged preset bytes are checked separately.

These are compiler, UI-adapter and send-adapter checks. No paid model request, installed-host observation or Android test was performed. A correctly assembled instruction cannot guarantee model compliance. Existing unregistered object/archive gaps remain gaps; identity material injection does not create database rows or authorize offstage settlement. Legacy opaque extension fields still require an actual registered compiled rule and are rejected when it is absent.
