## 实现

- 现有 `◆译文◆` 在显示时转成句下细线、小菱形、“译”印记与译文；`■心声■` 转成竖签、月牙与开放水纹。
- 正文、消息页、阅读器与流式显示共用 `formatProse`。在宿主格式化后的 DOM 上投影，不改消息、预设、协议、模型提示词或存档。
- 保护代码、链接、控件、媒体、带作者属性的 HTML 与已渲染区块。未闭合的标记保持字面可见；后续完整修订可以正常渲染。已有标记总开关、内心开关继续有效。

1. 放大长文时旋转装饰轻微撑宽页面，限制装饰范围并修正曲线后已复测通过。
