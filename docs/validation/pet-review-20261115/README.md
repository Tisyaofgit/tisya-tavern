## 证据与复现

`browser-evidence.json` 是实际DOM尺寸与点击后计数；四张JPEG均来自隔离测试页。`source-manifest.json` 对应最终发布源码与构建。用 esbuild 打包 `tests/browser-pet-review.mjs`，format=esm、target=chrome110；将 `import.meta.url` 指向测试页基址，配合 `tests/browser-pet-review.html` 与仓库 assets 即可复现。
