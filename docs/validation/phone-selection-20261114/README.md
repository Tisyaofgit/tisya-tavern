## 重复浏览器验收

使用静态预览承载整个源码树，打开 tests/browser-phone-selection.html。首次测试勾选“暂停读取人物资料”，点击生产页面“按当前资料初始化”，再“切换到人物乙”→“继续读取资料”→“核对实际保存”。切回甲并重开，再初始化；加入测试原图→编辑副本→边距 25%/10%、宽高 50%/80%→另存编辑副本→核保存→刷新。此夹具只生成合成原图，不访问用户文件。

当前托管服务不接受 static.directory 为点号；测试时将源码复制到预览根的 public 子目录，再用 sites-preview start 返回的 URL。生产文件复制前后按 SHA 核对。普通命令启动 Chromium 的 socket 权限失败属于另一条路径，不代表官方预览不可用。
