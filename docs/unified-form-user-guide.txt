缇斯亚统一表单与扩展呈现：使用说明候选
核对时间：2026-11-09 17:19 UTC（北京时间 2026-11-10 01:19）
状态：代码已接入本轮候选，正在总体验证与保存；这份说明不是已完成宿主或手机验收的声明。

一、现在保存在哪里

人物档案、世界与世界时间、小手机运行状态、资金和物品、消息及扩展内容，共用当前聊天的最新版表单。已有同义字段优先复用；手机独有字段放关联子表。书负责模板、参考和呈现定义，不再另存一份可修改的运行状态。

转账卡读取已经存在的资金流水；相册、音乐和语音卡引用实际媒体登记。打开正文、刷新阅读器或更换画风只读取内容，不付款、不发消息、不推进世界时间。未知余额、未登记账户和缺失音源不会被补成示例值。

二、先选当前人物和世界

打开“用户身份”。在“故事人物 · 当前表单”中选择主控模式和当前人物，点击“保存当前聊天绑定”。在“小手机对应世界”选择统一表单中的世界，再保存资料书与世界选择。

“编辑角色档案”按现有字段展示。修改后先点击“预览档案变更”，核对变化，再“确认提交档案变更”。这里只提交明确改动的字段，不重新套用人物初态，也不清空手机和已发生的故事。“更多档案字段”可查看其余可编辑字段；复杂结构仍需填写有效 JSON。

切换人物、世界或聊天后，应重新读取对应配置。不同主体或世界不共用一份手机资产；正在保存或还有未保存修改时，先保存或放弃当前修改。

三、三本内置书分别做什么

1. 缇斯亚模板书：给新人物、新世界等新内容提供骨架与约束，只在“从模板创作新内容”时读取，不拿模板覆盖已有运行状态。
2. 缇斯亚扩展资料书：定义论坛、弹幕、小剧场、新闻等区域允许生成什么内容，并提供可选择的参考定义。
3. 缇斯亚美化书：定义可选的排版风格与有限样式参数。内容仍来自表单和历史记录；美化条目不是可执行脚本，也不能创造交易或音源。

启动时会检查内置书，也可在“内置模板、扩展资料与美化书”点击“检查内置书更新”。插件更新与用户修改发生冲突时，会列出原版、当前和新版，供选择“保留当前内容”或“采用插件新版”。不会静默覆盖用户改文。

普通资料书可在“可选资料书启用”中按当前聊天选择；其条目仍遵守原生启用、关键词和触发条件。定义条目由对应编译器读取，不把整本美化书或模板书灌进故事。修改已选定义后，若原摘要不再一致，需要重新选择并保存，不会自动换成同名或第一条。

四、新生成与旧资料迁移

新建：在“从模板创作新内容”选择新人物或新世界，填写“要求与已有依据”，点击“生成表单草稿”。候选 JSON 与涉及字段会展示出来；核对、修改并解决待补项后，再点击“确认保存创作草稿”。也可通过“手动新建人物”先预览后提交。

旧角色：若仍绑定旧书籍角色，页面提供“预览迁移旧角色档案”。先核对原书 UID、内容摘要和字段差异，再明确提交。作者原文保留为来源；手机业务状态另做迁移核对。旧余额或时刻与已有表单冲突时会阻止迁移，不猜哪份正确、不相加、不用示例数据覆盖。

五、资金、物品与历法

手机账户引用统一余额记录，信用卡和贷款引用对应债务，物品、商品和地点复用或关联已有记录。转账、购买、借贷等动作继续使用实际报价与确认流程；手机只在结算归属和相关配置齐全时执行。

世界日期、时刻和手机日程读取同一世界时钟及历法规则。现有规则可表示固定月份、按月长度或固定季节等历法；月长、闰规则、每日小时数等来自配置。手机的时间显示和到期判断跟随所选世界，打开历史消息不会把时间推进到现在。

六、配置论坛、弹幕和消息呈现

在“用户身份”页的“小剧场与手机呈现”中点击“读取当前人物与世界配置”，再选择“配置区域”。目前区域包括近日留言、论坛、弹幕、小剧场、新闻、公告、风闻、结算展示。

启用区域后，选择“扩展内容定义”和“排版画风”，勾选允许的内容类型，再保存本区配置。配置归当前人物、世界及输出配置；切换后需重新读取。

“每轮新增条数”决定生成目标，范围 0—50；0 表示本轮不生成。“本次最多显示条数”范围 0—200，只限制本次展示，不删除历史。未填写不会自动变成任意默认数量。

“观众来自哪里”可选本位面的粉丝或居民、高维观众、混合来源、没有观众。类型不自动赋予知情：高维观众也不能凭这项设置读到人物隐私。需要观众的论坛和弹幕未指定观众时，不自动补造观众。

“更喜欢的主题”和“尽量少写的主题”每行一项，可写磕 CP、同人创作、日常八卦等偏好。这些只是创作偏好，不代表世界中已经发生对应事件。

“世界与观众材料来源”可引用已登记的表单记录或书籍条目；当前高级输入仍是 JSON 列表，可保持空列表。它没有自然语言自动检索全部书籍的能力，选择材料也不会扩大角色权限。

七、正文里的转账、语音、图片、新闻、论坛与弹幕

已有 25 类内容标记及“引用／媒体”标记继续保留。本轮新增记录引用方式，把消息子类型或扩展区块关联到真实表单记录及本条回复的历史快照。转账展示既有流水金额和状态；图片显示实际图片资源；语音使用真实音源的播放控件，缺音源时保留文稿并明确提示。不会由一段文字假装已经转账或生成语音。

论坛保留稳定楼层、引用关系和删除状态；显示上限不会改写或删除原楼层。弹幕读取已登记的条目和时间信息。之后继续盖楼或修改当前状态，不会把旧正文偷偷换成最新内容。

本地手机媒体读取已有原件库中的授权资源；远端资源使用已登记且允许的真实地址。仅有资源 ID、失效地址或任意本地路径不等于能播放；独立表单资源若没有可读取的实际地址或已关联手机原件，会显示缺少资源。不会自动合成 TTS，也不自动播放声音。

旧消息没有可核对的稳定身份、原文摘要或历史快照时，会明确缺项，不用当前表单冒充旧时刻。呈现读取不初始化、迁移或写回表单；关闭或替换阅读器时释放临时媒体地址。
