# 主页操作与启动 · alpha31.22

角色行打开原角色页，聊天行打开对应会话；独立 `>` 和长按打开同一操作菜单。`几段` 按钮展开/收起，避免与进入角色页冲突。拖动、滚动、多指、离页取消长按，长按结束吞掉随后的一次点击。

重命名是个人列表显示名，随界面设置保存，留空恢复原名。角色原名、卡设定、聊天文件和正文不改。置顶排序先按手动置顶时间，再沿会话原日期；同名角色与同名聊天按 avatar / file 独立。设置键 `会话目录` 使用 JSON 序列化的稳定身份作为键，每条仅 `名称` 与 `置顶`，失败/并发变化明确报错，不重置其他设置。删除会话/角色先显示确认，再调用宿主接口并复查目录；活动会话先关闭，避免自动保存复活；删除角色保留关联聊天文件。

设置打开完整菜单。USER 下方为「用户入口 ↗」，移除默认水相说明，最近会话面板为半透明黑色。原生抽屉打开时保留当前页面；宿主启动时异步加载旧聊天不会撤掉主页，依赖具体聊天的手记/配置/阅读仍随上下文失效。

`manifest.json` 加载 `runtime.js`，由 `npm run build:extension` 从 `index.js` 等107个本地模块打包。宿主导入保持外置，资源仍从扩展根解析；构建会拒绝未处理的嵌套模块 URL。`npm test` 检查产物与源码一致。启动时先发起异步显示缓存，再挂载主页；不等待空白聊天的协议初始化写入完成，注册生成协议仍在当前同步任务完成。

发流幅度加强，脸/颈 y=80..420 保持几何固定；男女周期12/16秒。仅文档隐藏、减少动态或用户手动暂停才停止帧；Android无对应focus事件的短暂blur不会把动画永久停住。背景不做大幅移动。

无性别第三相尚为独立审图稿，未替换已批准男女图。尚未接管完整聊天数据库/读取缓存。桌面浏览器测试使用隔离宿主API夹具，不是Android或用户数据库；具体启动秒数和目标设备动态效果待用户确认。
