# 0.2.0-alpha.23 · 可关闭记忆，使用数据库

配置 → 上下文与数据 → 记忆与上下文，可选“数据库／原生”或“缇斯亚”。更新后，未选择过这一项的旧会话和新会话默认使用“数据库／原生”。开关按会话保存。

- 数据库／原生：关闭缇斯亚窗口外记忆补入，主请求交由宿主和其他扩展装配；不重写消息、API 或工具，不拦截数据库后续注入。主聊天使用原生 API、预设、历史和世界书设置。
- 缇斯亚：恢复原来的所选资料装配、独立主聊天路由和窗口外记忆开关。原设置保留，切换不会删除聊天或记忆。

界面、旅程回看、心声表情、快捷栏和常用语保留。原生模式中的历史净化和数据库填表由原生设置及相应扩展负责；缇斯亚不会再对整条主请求进行核验或加工。“上下文一览”明确标注该模式仅观察当时请求，其他扩展仍可继续处理。

更新扩展并重启即可，无须重新导入预设。表单记忆与多 API 重构仍在设计阶段，本版没有接入该系统。

验证范围与结果见 docs/alpha23-validation.json。第三方数据库真实模型填表及 Android 设备仍需实测，未将兼容通道检查称为数据库全链路验收。
