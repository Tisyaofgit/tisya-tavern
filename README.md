# 缇斯亚 · 月潮界面 0.1.0-alpha.5

这是开发中的全局前端扩展源码，当前仅适配 TauriTavern 2.3.0，尚不保证标准 SillyTavern 可直接加载。**不是完整版发布，也不是可直接在主题导入器导入的 JSON**。目标：TauriTavern 2.3.0，源码 a1855be4a4f8b6ee7cd0374a84dbb3709c3e5375。不修改 APK。

## 已实现

- 独立会话首页、联系人列表、作者标签搜索、自定义分组；分组依据精确头像文件名关联。
- 角色卡详情通过原生 `/api/characters/chats` 读取该角色全部会话，选择后调用原生选卡/开聊天。
- 墨绿水纹、淡金、原 THM 字体与星芒分隔，聊天无头像、无气泡，输入框发送/停止仅图标。
- 消息下重骰、继续、更多。所有已加载消息可重骰/继续；历史位置自动删除下方消息再生成。AI重骰重写该条；用户消息重骰从该条重新生成。继续保留选中条并生成下一条；已有草稿时拒绝操作。
- 长按或更多菜单：原生改写、原生创建分支、复制原文、单条删除、回溯范围确认。
- 删除前验证聊天、消息对象、完整正文、候选和数量；回溯不删除未加载的后续历史。执行后保存失败会报告部分完成，不伪装成功。
- 原生九入口全部文字化放入侧边导航；原生管理页保留并加月潮材质；消息原生和第三方按钮通过更多显示，保留原节点及原事件。
- ChatSurface 早期 hook 注册按钮生命周期；管理投影时不启动 DOM watcher。静态模式使用限 #chat 的观察。
- 返回原生界面移除自有布局与监听，保留配置，不删除原消息和第三方节点。

## 安装边界

TauriTavern 此版本的扩展安装器接受匿名 HTTP(S) Git 仓库地址，源码预检要求根目录含 manifest.json；它不提供将这个 ZIP 当作扩展导入的路径。因此本包用于代码审查和开发。不要导入主题或角色卡管理器。

开发环境可将本目录放到当前用户的数据根扩展目录 `extensions/tisya-moon-tide/`（global 路径以当前宿主扩展目录为准），再由扩展发现器加载；必须核实际 data_root，Android 未测，不建议手改手机应用私有目录。发布阶段需要以此目录为 Git 仓库根并完成设备验证后再提供安装 URL。

## 验证

`npm install` 后 `npm test`。仓库不内置大字体；测试首次会下载固定资源提交的完整字体夹具。
21 项测试通过（含字体下载/持久缓存/校验失败/退出取消、全会话归组与读取失败显示）：过期消息/候选/分支拒绝、数量变化和未加载消息拒绝、同名联系人分组隔离、页面分组与卸载、继续与草稿保护、编辑与生成冲突。
壳层测试使用 Happy DOM 模拟宿主依赖，明确不代表真实酒馆或 Android。
浏览器截图验证因 Chromium 下载得到损坏包未执行。宿主源码独立运行 pnpm run check 的结果另记在工作区，不冒充扩展运行验收。

素材来自自有 Tisya THM 0.2.6；字体许可证在 assets/FONT-LICENSE.txt。

## 字体下载

安装使用系统默认字体。启动独立检查本地/user/files/缓存；缺失时从resources分支的固定提交URL下载四个资源片，合并后以SHA-256核对原字体，调用宿主文件上传保存并读回，最后加载FontFace。字体下载不占用模型请求，不阻塞聊天；导航显示阶段与错误并提供重试。超时两分钟，卸载界面取消。Android首次下载/跨重启缓存待实测。资源分支不在main安装树中。

## 历史回溯与继续设置

选择任意旧消息后点重骰或继续，会自动删除下方消息、保存，再调用宿主生成。删除或保存失败停止后续生成并显示已删除数量；未完整加载的历史拒绝删除。菜单里的“继续设置”可保存自动发送的用户消息，非空时经原生输入框进入普通生成；留空直接生成下一条，重骰不使用此文字。输入栏常驻菜单、＋、发送/停止，其他原生及第三方节点按＋原位展开。
