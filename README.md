# 缇斯亚 · 月潮 0.2.0-alpha.4

TauriTavern 2.3.0 全局界面扩展开发版。更新仓库：<https://github.com/Tisyaofgit/tisya-tavern>。更新后重启应用；侧栏底部应显示 **0.2.0-alpha.4**。本扩展不重建 APK，不是可在主题导入器中使用的 JSON。

## 本版细化

沿用用户已确认正常的无顶栏布局，加入原版消息视觉、动画及桌宠 UI。

- 消息页接入原版标题、提灯、书页、挂坠、旅程面板、水母与蝌蚪，以及水波、流萤、火焰和摆动效果。正文、公开回合记录和行动沿用既有读取接口；世界、玩家和任务等尚未接入的页面明确显示待接入。
- 加入原版桌宠及折叠／展开手机，可拖动、轻点互动、隐藏，再从侧栏恢复。手机图标可打开对应 UI，业务功能留待后续接入。侧栏可暂停动态效果；同时尊重系统减少动态效果设置和离屏暂停。
- **下一条**旁新增**回底**，直接到聊天最底部。即使正在阅读最后一条长消息、下一条已不可用，仍可回底。上一条／下一条保持原有定位语义，只导航已载入的消息。
- **改写**时，原生保存、取消及其他编辑工具移到编辑区域底部并粘附显示。保存／取消在前，其余工具横向滚动可达；保留原生节点、父级和事件。
- 修复流式生成期间关闭菜单也被全局操作锁拦截的问题。菜单开关、阅读、复制、导航及外观设置独立可用；遮罩、返回键和关闭按钮均可退出。生成及修改同一聊天历史仍防止重复执行。迟到的复制／保存结果不会误关后来打开的面板。
- 输入框上方保留附件、上一条、下一条、回底、聊天和扩展快捷入口；左侧按钮组空间不足时横向滚动，Agent 保留上行右侧。按钮点击区域至少 44px。原生及第三方按钮留在原父级，主输入行、系统键盘和安全区继续由宿主处理。
- 消息下的重骰／继续／更多及底部菜单继续使用图标；聊天中重骰／继续保持每条消息单一入口。原生代写、脚本恢复、候选切换等独立功能保留。

消息外观使用隔离样式，原生消息节点和数据不改写；改写时恢复原文本编辑区，生成中暂缓重绘当前条。普通消息已有交互式 iframe 或自定义样式时保留原生呈现。返回原生界面会撤除这些视觉层。

## 消息操作

所有已加载消息下都有重骰、继续、更多。历史位置会自动删除后续消息再生成：AI 重骰重写选中条；用户消息重骰从该条生成；继续保留选中条并生成下一条。

“继续设置”可以自定义自动发送的用户消息。非空时通过宿主输入框和普通生成流程提交；留空直接请求下一条。输入框已有草稿、模型断开、正在生成或编辑时会拒绝操作。删除前验证会话、消息、候选和数量；后续历史未完整加载时不删除。删除或保存失败会报告部分完成并停止生成。

更多保留原生编辑、分支、复制、单条删除、范围回溯和扩展消息按钮。返回原生界面会移除扩展布局、监听及自有节点，恢复由扩展接管的装饰样式。

## 阅读与回合记录

从任意已载入消息的“更多”打开，提供正文、本回合、行动三个页面：

- 普通消息可直接阅读；结构化回复只提取正文，保留段落并统计可见文字。阅读排版使用宿主 Markdown 与净化器，不再次运行角色卡正则。原消息、原生富文本卡片和消息数据不改写。
- 本回合记录使用原 Foundation r243 的 `memory/5` 权限投影器。只有明确允许向读者输出的记录才能出现；父级、字段及嵌套权限全部保留检查。不显示任务、审计、私密记录、待办 / 倒计时壳或隐藏数量。旧格式没有所需权限时明确显示不可用。
- 记录属于选中消息的历史回合，不是当前状态总表。本版不推断玩家身份或别名，不写变量、不提交记忆；心理显示保持关闭。
- 行动建议只填入输入框，供用户修改后发送。已有草稿时选择追加、替换或取消；确认期间切换会话、修改消息或修改草稿会停止写入。选历史行动不会回溯或生成。
- 结构化回复损坏时不将整段内部载荷当正文显示；如果正文已完整闭合但后续字段未完成，正文仍可阅读，记录和行动分别报告错误。

13 个原始纯解析 / 投影模块逐字节保存在 `vendor/foundation`，来源和 SHA-256 见 `provenance.json`。`npm run build:reader` 生成无动态求值的浏览器模块；`npm test` 先核对来源哈希和构建一致性。原插件的提示词装配、实时状态、身份绑定、生成闭环等继续分批移植，本版不宣称完整移植。

## 字体与素材

默认字体立即可用。原 THM 字体从固定资源提交下载，SHA-256 校验后保存宿主本地文件，读回验证后启用。下载不阻塞聊天；侧栏显示状态并提供重试。原字体未放入主安装树。主题素材来自 Tisya THM 0.2.6，字体许可证见 `assets/FONT-LICENSE.txt`。

新增消息、桌宠及手机素材取自项目 r243 原资源：83 张 PNG 以原尺寸无损转换成 WebP，并逐像素核对 RGBA 一致；6 个 SVG 保留原文件。总计约 38.57 MB，更新时需下载。来源和哈希见 `assets/visual/provenance.json`。12 个原版几何／动画模块保存在 `vendor/visual`；构建时核对原文件哈希。素材加载失败会显示重试入口。

## 验证依据与限制

已对用户提供的 TauriTavern 2.3.0 APK 静态解包，从 Rust 动态库的 Brotli 资源中恢复实际前端。核心 HTML、CSS、布局防火墙、生成入口和附件处理等 21 个资源与源提交 `a1855be4a4f8b6ee7cd0374a84dbb3709c3e5375` 逐字节相符。

- `npm install` 后运行 `npm test`：90 项行为、导航、阅读权限、字体、视觉生命周期、底部编辑和流式生成并行 UI 回归全部通过。本地缺少字体文件时，字体测试会下载固定资源提交的四个分片。
- 用 APK 原始 DOM / CSS、旧主题、Agent 样式及宿主布局防火墙组合，在 320、360、390、768、1100px 五种宽度与键盘关闭 / 开启两种配置下进行 10 组 DOM / 样式模拟检查。覆盖零高度顶栏、常驻快捷栏顺序、回底入口、底部编辑、字号、发送 / 停止可见性、九入口和编辑器返回、图标尺寸、单一重骰 / 继续入口，以及关闭扩展后的原生恢复。
- 单独执行 APK 中的原生附件事件代码，验证快捷入口同步触发、追加与去重、文件摘要、移除和草稿保留；文件对话框及文件校验依赖使用模拟。
- Happy DOM 不执行真实页面排版。上述检查不代表新版 Android 视觉、系统文件选择器、键盘动画、真实模型请求或所有第三方扩展验收。手机排版确认来自 alpha.1 用户反馈，本版仍待设备反馈。
- 原版人物及手机已用原绘制器生成 Canvas 合成预览核对层次；该预览也不等同于手机截图。用户报告的 `TISYA_READER_INVALID` 仍待独立修复，本次 UI 移植不宣称解决协议解析问题。
- 原生管理表单仍由宿主编辑器负责；世界书身份绑定、全部管理字段的重新编排尚未完成。

开发环境可将此目录作为全局扩展根目录。普通用户使用宿主扩展安装器连接上述仓库；已安装的用户直接更新并重启，不必重装 APK。
