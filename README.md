# 0.2.0-alpha.21 · 读者记录与输入快捷栏

旅程按已交付回复显示事件、状态、人物认知。故事内 A–E 分类与人物实际知情继续独立保留，不再拿它隐藏读者记录。旅程→更多恢复角色心理显示开关；本人认知显示在精确匹配的玩家页，未匹配的记录保留在角色页。未完、倒计时、未来伏笔仍不进入读者记录。

输入栏有七个可配置位置及固定“更多”。在更多→配置位置选择功能；未选功能收入更多，Agent 默认在更多中。常用语支持新增、修改、删除，点击即追加到现有输入框，不自动发送。

心声规则归并为一处，首尾模板仅保留开篇/收篇短评占位；移除重复复核段与末尾重述。已有回复保留原文。更新扩展并重启即可使用，旧 alpha.13 / alpha.20 预设通过现有宏读取新版规则，无须再导入一套预设。

验证区分：本地自动化与 Chromium 窄屏检查；未调用真实生成模型，未在 Android 设备验收。token 实验见 docs/token-study，语言版本仅用于比较，不覆盖当前动态配置。
