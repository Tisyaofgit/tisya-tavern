# 缇斯亚 · 月潮 0.2.0-alpha.16

TauriTavern 2.3.0 全局扩展。更新仓库：<https://github.com/Tisyaofgit/tisya-tavern>。

## 更新与试用

1. 在原生扩展管理中更新本扩展，完全重启应用，确认菜单底部版本为 **0.2.0-alpha.16**。
2. 继续使用已导入的 `presets/Tisya-TauriTavern-0.2.0-alpha.13.json`；本版动态宏接口未变，无须重新导入。首次安装仍需导入并选用这份预设。
3. 快捷菜单第一项 **配置**进入五页设置。先保存，再生成。通用 API 和预设未设置时沿用原生当前选择。
4. 本阶段配套叙事使用**普通生成**。原生 Agent 开启时会提示先关闭；Agent、媒体、创世等专用执行器尚待接入。
5. **上下文一览**可查看最近十次本应用主请求／辅助请求装配快照。它显示送往宿主后端的消息，不冒充供应商计费或实机调用回执。

扩展更新不会改写用户已导入的预设。本版沿用 alpha.13 配套 JSON，编译修复随扩展更新生效。旧预设与旧回复仍保留。配套预设依赖本扩展的动态宏，不能单独在未安装扩展的酒馆使用。

## 本版修复与新增

- 权限栏支持 `A–E`、小写 `a–e` 和公开标记 `~`。`A`／`~` 为公开；其他等级不自动公开，也不由同场或参与者名单推定角色知情。原有精细权限及字段限制继续支持。
- `~` 在其他栏仍按原协议表示缺失或删除；名称列表兼容顿号和方括号写法。只转换读取副本，不改写历史消息。
- 无对应字段、冲突或缺失的原生字段权限单独提示并隔离；独立有效的叙事记录、标题、任务、心声、核验和行动仍可读取。不会把坏权限补成公开。
- 变量权限定位核对操作的实际 `path`；原卡扩展识别 XML 子字段及 `[Field|value]` 字段行。读取不执行变量操作。
- 三档编译结果同步简写权限说明，取消强制四格的提示；关闭 MVU 时只输出 `<vars/>`，不再同时提供变量操作和权限行模板。

- **思维链详细程度**位于「配置 → 本模式配置 → 工作流」，可选完整、精简、仅格式与配置。完整档保留原版分阶段输入、结果、依赖、检查和逐段成稿；精简档保留已选步骤摘要；最低档保留选中配置和固定输出协议。当前默认与旧配置均为精简，保存后下一次生成生效。此项调整提示词工作流，不更改 API 推理强度。
- 旧九块回复中的 `task/title/next format="yaml"` 按宿主 YAML 读取，不再误送 JSON 解析器。标题、心声、七项核验与行动可正常展示；现行十块 pipes 和旧 JSON 继续支持。读取不改写原消息，不执行变量操作。
- 旧记忆缺少现行公开权限记录时仍保留为不可投影状态，不推测授权；这不阻塞其他已可读取的界面。

## 本版配置

| 位置 | 已接入内容 |
| --- | --- |
| 顶部 | 已登记模式切换、Agent 方案引用／原生设置入口、共用上下文一览 |
| 本模式配置 | 叙事授权、视角、篇幅、摘要、行动建议、心声方向、可选工作流、默认扩展与增强资源 |
| 主题配置 | 原生正则正文覆盖、原有月潮显示编辑器、载入资源的自动扩展字段 |
| 世界配置 | 自动扫描的主控和关注对象、主／补充文风输入与保存、世界书检索、难度／中心化／边界及内部开关、资源三态覆盖 |
| 预设与 API | 通用、模式、任务三级独立 API／预设／模型／参数选择；原生连接、凭据和预设管理入口 |
| 上下文与数据 | 历史条数、宿主文本 token 预算、角色／persona、世界书范围与逐条选择、配置备份、资源导入 |

主控候选包括角色卡、原生 persona、选中书籍中带 `tisyaArchive` 元数据或可识别名称／类型的 JSON 档案，以及已登记扫描器的档案。不限制人物、组织、群体或物件类型；只使用实际身份说明，不自动授予隐秘知识。没有正式档案数据的历史消息不会被猜造成档案。

主文风不再内置“自然小说”等默认选项。文风、扩展、标记、工作流增强、其他要求可输入、保存、编辑或从所选世界书精确取用。**保存／导入不自动选中。** 已保存世界书资源发生变化时先停止，供用户预览刷新。

世界扩展采用 **继承／额外启用／禁用**；禁用优先，依赖冲突必须解决，程序不会偷偷补回。API 和预设各自按 **任务覆盖 → 模式绑定 → 通用 → 原生当前值**解析；连接档案携带的预设不会暗中替换本页的预设选择。显式“无附加预设”与继承不同，主聊天仍保留配套必需协议。

配置保存在宿主扩展设置中，按世界／聊天分支隔离；首次打开可读取 alpha.12 叙事选值。新的统一配置成为权威来源后，不再依赖旧变量的后续改动。保存有版本前置、宿主成功回执和聊天切换保护。备份不复制原生连接凭据；新设备需重新核对连接引用。

## 提示词装配与显示

- 固定身份来源、十块回复协议和已有消费者保留；可选工作流与规则在代码侧按选择编译。默认标记目录已从配套预设移除。
- 请求只装入有效资源及其实际参数，主文风为空就不附加主文风。未选资源的名称、正文、描述、示例和表单不发送。
- 原生世界书自动／递归／深度注入不旁路进入配套请求；第五页选择书籍只是检索范围，具体条目或已保存资源被选中后才注入。
- 原生当前角色、persona、历史和已发送附件受第五页范围控制。当前输入始终保留。主控已指定时不再并入原 persona 描述。多媒体无法准确对应时明确停止，不静默丢图。
- 主／辅助任务分别取适用资源。辅助任务不会复制叙事十块输出工作流；自选辅助预设按启用条目与顺序读取。辅助 API 返回候选结果，不自动写数据库或世界书。
- 预算由宿主分词核验文本；超过预算就停止，固定协议不截断。多媒体及服务商消息包装成本另计。
- 发送前封存已核验请求。后续扩展修改请求，或 API 附加请求体试图覆盖消息／工具时停止，避免未选内容绕过选择。
- 其他插件自行调用的原生 quiet／impersonate 请求继续由其原有链路管理；不计入本应用的裁剪或快照承诺。不可拆分外部主预设也不宣称支持完整选中项裁剪。

**角色卡美化**：普通卡片消息保留宿主已经渲染的原节点、按钮事件和 iframe 生命周期；结构化回复只把已解析的公开正文交给原生正则、Markdown 和净化器，不再强制剥掉卡片的静态 HTML/CSS。正文段号继续隐藏，协议旁块不进入美化正文。原生正则的启用与角色卡授权仍以宿主为准，不自动授权卡片脚本。结构化正文中的酒馆助手脚本 iframe 另需渲染适配；本版没有宣称任意脚本卡均可在 Shadow DOM 内运行。

## 扩展接口与当前边界

公开入口 `window.Tisya` 提供配置读写、模式／任务／资源／档案／主题／执行器登记、辅助请求、上下文快照和生成产物契约。详见 [配置与接口说明](config/README.md)。未来创世产物进入同一个资源库，仍需选用；当前没有创世界面。

原生 Agent、MCP／Skill 工具筛选、专用媒体、MVU、数据库权威写入、向量检索及自动工作流执行器保持待接入。主题资源本版自动显示参数表单；新渲染器的安装执行由后续适配器负责。现有月潮外观编辑器、任务／待办／心声、公开记忆查看、行动菜单、角色卡与会话入口继续保留。

## 验证

`npm test` 包含构建产物核对和回归测试，本版 204 项通过。另使用 APK 提取的前端布局、CSS、原生 YAML 库与正则引擎，在 Chromium 中检查 320／360／709 像素下的简写权限、局部定位提示、标题／心声／核验／行动、续接草稿、重挂载折叠状态和旧 YAML 兼容；三档实际装配请求均核对新规则。网络、持久化服务及正则工作线程使用离线夹具；没有把这些结果当作 Android 实机、真实模型或供应商认证通过。
