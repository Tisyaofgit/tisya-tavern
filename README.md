# 缇斯亚 · 月潮 0.2.0-alpha.1

TauriTavern 2.3.0 全局界面扩展开发版。更新仓库：<https://github.com/Tisyaofgit/tisya-tavern>。更新后重启应用；侧栏底部应显示 **0.2.0-alpha.1**。本扩展不重建 APK，不是可在主题导入器中使用的 JSON。

## 本版重构

- **移除常驻顶栏并释放占用高度**。输入栏左侧“菜单”打开侧栏；会话、联系人、创作、资料、工作流、系统按层级排列。原生编辑器打开时提供返回与菜单操作。
- 原生“系统全屏”入口在支持的 Android 宿主上保留，沿用现有全屏偏好。
- 正文、会话页跟随宿主布局和安全区；键盘避让继续由宿主处理。自有对话框显式声明表面类型，避免自动浮层分类改变尺寸。
- 常态输入栏只有菜单、输入框、发送/停止。侧栏“输入工具”展开附加操作，按双列排列；原生和第三方节点保持原父级和事件。脚本暂停/停止继续服从宿主显示状态。
- 界面使用系统字体 14–16px，正文使用阅读字体 17px；主要按钮点击区域至少 44px。会话标题限制两行，摘要一行，列表预览去除结构标签，不修改消息原文。
- 原生九个设置入口按面板 ID 绑定，未知扩展入口自动保留。Agent、Skill、MCP 已挂载时，侧栏可直接定位并展开原生设置区域。
- 旧主题的背景条、按钮文字伪元素和尺寸不再主导新布局；本版改用独立 `shell.css`，侧栏检查样式版本是否匹配。

## 消息操作

所有已加载消息下都有重骰、继续、更多。历史位置会自动删除后续消息再生成：AI 重骰重写选中条；用户消息重骰从该条生成；继续保留选中条并生成下一条。

“继续设置”可以自定义自动发送的用户消息。非空时通过宿主输入框和普通生成流程提交；留空直接请求下一条。输入框已有草稿、模型断开、正在生成或编辑时会拒绝操作。删除前验证会话、消息、候选和数量；后续历史未完整加载时不删除。删除或保存失败会报告部分完成并停止生成。

更多保留原生编辑、分支、复制、单条删除、范围回溯和扩展消息按钮。返回原生界面会移除扩展布局、监听及自有节点，恢复由扩展接管的装饰样式。

## 字体与素材

默认字体立即可用。原 THM 字体从固定资源提交下载，SHA-256 校验后保存宿主本地文件，读回验证后启用。下载不阻塞聊天；侧栏显示状态并提供重试。原字体未放入主安装树。素材来自 Tisya THM 0.2.6，字体许可证见 `assets/FONT-LICENSE.txt`。

## 验证依据与限制

已对用户提供的 TauriTavern 2.3.0 APK 静态解包，从 Rust 动态库的 Brotli 资源中恢复实际前端。核心 HTML、CSS、布局防火墙和生成入口等资源与源提交 `a1855be4a4f8b6ee7cd0374a84dbb3709c3e5375` 逐字节相符。

- `npm install` 后运行 `npm test`：30 项行为及字体测试。
- 另外用 APK 原始 DOM、原始 CSS、旧主题和宿主布局防火墙组合，在 320、360、390、768、1100px 五种宽度配置下做 DOM / 样式模拟检查；覆盖零高度顶栏、输入工具展开、九入口映射和编辑器返回。
- Happy DOM 不执行真实页面排版。这些检查不代表 Android 视觉、键盘动画、真实模型请求或全部第三方扩展兼容性验收。云浏览器无法打开本地测试夹具，本轮没有可用的浏览器截图证据。
- 原生管理表单仍由宿主编辑器负责；世界书身份绑定、全部管理字段的重新编排尚未完成。

开发环境可将此目录作为全局扩展根目录。普通用户使用宿主扩展安装器连接上述仓库；已安装的用户直接更新并重启，不必重装 APK。
