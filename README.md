# 缇斯亚 · 月潮 0.2.0-alpha.2

TauriTavern 2.3.0 全局界面扩展开发版。更新仓库：<https://github.com/Tisyaofgit/tisya-tavern>。更新后重启应用；侧栏底部应显示 **0.2.0-alpha.2**。本扩展不重建 APK，不是可在主题导入器中使用的 JSON。

## 本版细化

0.2.0-alpha.1 的手机排版已获用户确认正常；本版以它为布局底座，恢复月潮材质并调整输入快捷栏。

- **月潮美化**：恢复原 THM 0.2.6 的墨绿水纹、淡金嵌边、玻璃质感按钮和星芒分隔。输入框、消息操作、会话列表、侧栏与原生设置面板使用统一材质。
- **常驻输入快捷栏**：附件、聊天菜单、扩展、Agent 及宿主当前可用的接写 / 代写 / 脚本操作排在输入框上方。按钮多时向上换行，不再需要展开下半区。复杂扩展控件保留整行空间。
- **附件直接可达**：点“附件”调用宿主的文件 / 图片附件入口，保留多文件追加、去重、文件摘要和移除流程；不替换文件处理器，不清空输入草稿。附件功能未加载时明确提示。
- 原生和第三方按钮仍在原父级，保留点击、Agent 长按、状态灯和原生显示条件。后加载的按钮自动加入快捷栏。
- 主输入行继续使用 44px 菜单、弹性输入框、44px 发送 / 停止；系统字体、正文 17px 阅读字体、页面宽度和宿主键盘 / 安全区处理沿用稳定版。顶栏保持隐藏，菜单仍从侧栏进入。
- 原生九个设置入口按面板 ID 绑定，未知扩展入口保留。Agent、Skill、MCP 已挂载时可从侧栏定位原生设置区域。

## 消息操作

所有已加载消息下都有重骰、继续、更多。历史位置会自动删除后续消息再生成：AI 重骰重写选中条；用户消息重骰从该条生成；继续保留选中条并生成下一条。

“继续设置”可以自定义自动发送的用户消息。非空时通过宿主输入框和普通生成流程提交；留空直接请求下一条。输入框已有草稿、模型断开、正在生成或编辑时会拒绝操作。删除前验证会话、消息、候选和数量；后续历史未完整加载时不删除。删除或保存失败会报告部分完成并停止生成。

更多保留原生编辑、分支、复制、单条删除、范围回溯和扩展消息按钮。返回原生界面会移除扩展布局、监听及自有节点，恢复由扩展接管的装饰样式。

## 字体与素材

默认字体立即可用。原 THM 字体从固定资源提交下载，SHA-256 校验后保存宿主本地文件，读回验证后启用。下载不阻塞聊天；侧栏显示状态并提供重试。原字体未放入主安装树。素材来自 Tisya THM 0.2.6，字体许可证见 `assets/FONT-LICENSE.txt`。

## 验证依据与限制

已对用户提供的 TauriTavern 2.3.0 APK 静态解包，从 Rust 动态库的 Brotli 资源中恢复实际前端。核心 HTML、CSS、布局防火墙、生成入口和附件处理等 21 个资源与源提交 `a1855be4a4f8b6ee7cd0374a84dbb3709c3e5375` 逐字节相符。

- `npm install` 后运行 `npm test`：32 项行为及字体测试。本地缺少字体文件时，字体测试会下载固定资源提交的四个分片。
- 用 APK 原始 DOM / CSS、旧主题、Agent 样式及宿主布局防火墙组合，在 320、360、390、768、1100px 五种宽度与键盘关闭 / 开启两种配置下进行 10 组 DOM / 样式模拟检查。覆盖零高度顶栏、常驻快捷栏顺序、字号、发送 / 停止可见性、九入口和编辑器返回。
- 单独执行 APK 中的原生附件事件代码，验证快捷入口同步触发、追加与去重、文件摘要、移除和草稿保留；文件对话框及文件校验依赖使用模拟。
- Happy DOM 不执行真实页面排版。上述检查不代表新版 Android 视觉、系统文件选择器、键盘动画、真实模型请求或所有第三方扩展验收。手机排版确认来自上一版用户反馈，本版外观仍待设备反馈。
- 原生管理表单仍由宿主编辑器负责；世界书身份绑定、全部管理字段的重新编排尚未完成。

开发环境可将此目录作为全局扩展根目录。普通用户使用宿主扩展安装器连接上述仓库；已安装的用户直接更新并重启，不必重装 APK。
