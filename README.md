# 0.2.0-alpha.25 · 表单推进与辅助 API

新增 **配置 → 表单推进**：12 张基础业务表、角色卡原点书、独立会话存档、创世草稿、自动归档、剧情推进、偏好分析与原生向量检索。默认关闭，历史条数和原生／数据库模式继续独立保留。

**旧会话可以救回：** 自动扫描当前会话，按楼层范围批量补录，支持停止和续跑，跳过已归档内容；默认排除最新 AI 回复。聊天外的往事支持手写／文本导入，先看填表草稿再保存。

原点档案按版本复用，改写或重投后撤下失效来源；既有 memory 摘要原样保留，辅助 API 不另写重复总结。各任务默认使用主聊天连接与模型，使用独立提示词，可分别配置 API。

需要新版酒馆助手世界书接口。更新扩展并重启后，先绑定世界书、补录历史，再按需启用。完整使用方法、验证范围及已知限制见 [表单推进说明](docs/alpha25-tables.md)。本版尚未经用户真实 API 或 Android 实机验收。

表单上下文默认走原生世界书蓝绿灯：上回合引用临时必带，其余档案按关键词激活，遵守原生预算；完整存档账本不注入。当前表单可查看激活清单。

# 0.2.0-alpha.24 · 独立历史范围与通用输出路由

**历史聊天条数保留，两种上下文模式均生效，与记忆推进独立。** 配置 → 上下文与数据 → 历史范围，设置 N 条历史后保留近期 N 条及当前输入。原生模式在宿主的历史输入阶段选取发送副本，原始聊天、附件和当前分支不改动；最终仍受宿主 token 预算限制。

旧记忆推进已移除：不再提取、解析或补入历史记忆块。没有记忆的开场白、普通消息和畸形旧记忆块均不再阻断发送。alpha25 的新表单流程独立启用，任务和执行器登记接口保留。

上下文来源仍可选择“数据库／原生”或“手选资料”。前者沿用原生 API、预设、世界书及数据库扩展；后者保留所选资料与独立路由。切换不重置已保存设置。

**变量位置由预设输入预处理及输出流程统一处理，不改写最终请求中的原卡格式。** 资料层组件按作用归入 extra（显示）、vars（变量更新）、status（状态记录），贯穿 TASK.START、C.2 和相应输出块。所有已提供的有效外部变量协议均可路由，不按卡名或某一种 MVU 脚本筛选。保留原协议的字段、标签和运算语法；“回复末尾”在 vars 内完成，Analysis 留在内部。

阅读层识别 JSONPatch；其他原生更新语法保留为不执行、不公开的原文，仍交原卡脚本结算。已保存的旧回复若 vars 为空且末尾只有一份合法 JSONPatch 更新，可回看；不改 mes、不重放更新。重复尾块和异常尾文仍报错。

更新扩展并重启。现用实时配套预设自动载入新预处理规则；静态旧预设需改用配套实时预设。心声表情、旅程回看、快捷栏和常用语保留。

验证及设备边界见 `docs/alpha24-validation.json`。原生模式的“上下文一览”是观察时点的快照，其他扩展仍可继续处理。

消息下方的快捷排也可配置：点该消息的“更多 → 配置消息快捷栏”，按顺序选择按钮；未选操作收入更多。支持仅保留更多、任意少量按钮或全部展开，“更多”本身也可换位置。与输入快捷栏分开保存。

变量兼容验证使用酒馆助手公开的 Mvu 接口契约，以及 MagVarUpdate 上游提取函数；JSONPatch、旧 `_.set`、CDATA 和补丁内命令字面量均做了隔离检查。美化不调用 parseMessage / replaceMvuData，不额外注册变量写入监听。仍需原卡启用对应变量脚本；不内置或复制酒馆助手。
