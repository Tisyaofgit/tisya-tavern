# 缇斯亚 · 月潮 0.2.0-alpha.12

TauriTavern 2.3.0 全局界面扩展开发版。更新仓库：<https://github.com/Tisyaofgit/tisya-tavern>。更新后重启应用；侧栏底部应显示 **0.2.0-alpha.12**。本扩展不重建 APK，不是可在主题导入器中使用的 JSON。

## 本版接通原版小手机设置

**更新扩展并重启后，请另行导入并选用 `presets/Tisya-TauriTavern-0.2.0-alpha.12.json`。** alpha.10 的固定预设仍能显示原消息，但不读取这次新增的动态叙事设置。扩展不会覆盖你编辑过的预设。

- 小手机 **设置**进入原版“模式配置／聊天配置／主题配置”；**主题**直接进入主题页；**协议**进入回复与行动设置。原叙事表单、外观预览、选项按钮和方案编辑器直接复用，隔离宿主主题样式，避免按钮和勾选框被外部 CSS 改坏。
- 原版支持的创作模式、代写权限、人称与知情、文风节奏、语言、篇幅、公开摘要、行动范围、写作步序和增强选项均接入原编译器。14 个原条目使用只读动态宏展开，角色、顺序、身份正文和原生资料槽保留。手动改写的条目仍归你管理；宏不会重写它们。
- 叙事设置按 **当前聊天**保存；**新聊天默认**只在未配置的新会话首次初始化。也可手动采用默认或保存命名方案。保留 false、空数组和其他原生变量；渲染及宏展开不写存档。
- 十块输出、三个心声方向共用当前原生预设的同一组开关。小手机和原生提示词列表互相读回；不再另存另一套心声选择。已生成的消息按原内容保留，关闭不会删改历史气泡。场外讨论、总结和工具任务沿原编译器使用各自交付格式。
- 主题接通通用及各区块装饰、动画；正文分段、缩进、行距、段间距、对白／标点高亮和各类短标记；背景组合、点触涟漪、挂坠开合及旅程纸色。保存后立即刷新显示，并保留消息的手动折叠与心声页码。主题方案可另存、载入、更新、改名及删除；载入先成为草稿。
- 保存走 APK 对应的原生聊天保存队列和确认式元数据提交；不把宿主取消保存当成成功。切换聊天、预设或外部改动会阻止旧草稿覆盖新配置。跨聊天配置与原生预设的部分成功会明确提示。
- 人物／世界绑定、MVU、辅助 API、正式记忆档案与备份服务尚未移植，设置页对应入口明确停用。当前任务中的世界书／角色卡／世界生成只编译创作要求，不冒充完成导入或状态写入。自动词条匹配控制暂不显示。

## 保留的原版任务、待办与心声


- 恢复 r243 原版的“本轮任务”“下轮待办”按钮、首尾布局、计数珠和折叠账页，复用原模板、原账页渲染器和原图标。核验回到“下轮待办”的折叠内容内。
- 首尾心声回到原水滴气泡，保留点击翻页和逐条表情；水母属于开篇心声，蝌蚪属于收篇心声。删除无心声时把两只小动物集中到页尾的错位布局。长文字随气泡自然增高。
- 本轮任务只显示原版允许展示的计划摘要。待办只显示同时属于本条下轮待办、并通过原版读者权限核验的记忆事项；内部计划、候选分支和未授权记录不转成正文。
- 展开状态、账页内层折叠与心声页码在同一消息重挂后保留。没有世界扩展内容时默认收起空卷轴，仍可手动打开；有内容的世界扩展继续沿显示偏好和手动状态。
- 十块回复协议继续兼容。旧消息若写着“心声：关闭／沉默”，仍遵守原意；需要验证完整显示时，用 `examples/reply-demo.txt` 编辑一条测试 AI 消息。

## 已接入功能与配套预设

- **三个心声方向可以独立开关**：导入本版配套预设后，在原生聊天补全预设的提示词列表切换“心声 · 输入评价”“心声 · 回应用户评价”“心声 · 剧情吐槽”。开关直接属于原生预设，不另存一份配置。更改从下一次生成生效；全关会要求首尾写“心声：关闭”，不会强行恢复三个默认方向。只关部分方向时，剩余方向的原指令、首尾格式与可用表情一起随选择调整。
- 三个方向 × 结构化输出的 16 种组合都用真实原版编译器与实际原生宏展开逐条比对。旧 alpha.8／alpha.9 预设没有新增开关，继续保持原来的三个方向；要用新开关需导入 alpha.10。

- **世界扩展**读取回复的 `extra`，按原版完整信封与公开权限规则分区。顶层 XML 分页，内层仍属于原页；支持 Markdown、静态 HTML/CSS、CDATA、HTML 围栏和原生折叠。正文与静态卡片样式隔离，中文字体跟随主界面，内容高度随折叠变化。阅读页也新增“世界扩展”。
- 卡片脚本、外部库、交互按钮、媒体及原生角色卡正则的完整显示管线尚未接入。需要这些运行时的页面会明确提示并保留该页已获公开权限的原始文本；不把私密区块当后备内容，不逐页重复运行正则。
- **图鉴 → 内置表情**接上困倦、好奇、开心、怀疑、惊讶、闹别扭六张原图。心声逐条使用自己的表情名，`null` 不配图；未知或加载失败有明确提示。图鉴、心声和配套预设共用一个资源目录。自建档案、资源编辑和角色绑定仍待移植。
- **主题 → 显示配置**接入背景组合／主动轮换／关闭、水纹、涟漪、雨、雪、萤火、点触涟漪、上一条落点、两枚挂坠默认开合及旅程日夜纸色。更改先留在草稿，点应用才写原生扩展设置；仍可进入原生主题与字体管理。
- 自定义值优先，选“继承”只清除该项覆盖，不把注册默认值复制进存档。开合缺省沿原版注册默认“展开”，纸色为“日间”；没有内容的世界扩展初始收起。可以在显示配置改成收起／夜间。手动开合、页签、内层折叠和旅程纸色优先保留；只调背景不重建正文。
- 旧配套 `presets/Tisya-TauriTavern-0.2.0-alpha.10.json` 由 r243 / 0.11.2 原编译器生成，原身份和既有角色顺序保留，新增三个空内容的原生开关条目。表情宏读取已解码图鉴中的表情名；输出关闭时回到原编译器的普通交付。扩展更新不会覆盖当前预设，需另行导入并选用新版预设。
- `examples/reply-demo.txt` 含本轮任务、一条公开待办、本轮交付、首尾心声及表情、两页世界扩展和七项核验，**编辑一条测试 AI 消息**即可检查；发送成 User 消息只作为原文，不会触发 AI 协议解析。普通美化标记仍可用 `examples/prose-demo.txt`。

alpha.8 的亮灯、卷轴接合、羽毛笔原位行动菜单、心声／核验与隐藏段号均保留。所有角色卡继续共用月潮外观；既有原图和 r243 正式基线不修改。

## 已接入的手机入口

沿用此前界面和入口：

- **手记**：浏览当前会话已载入的对话正文，最近消息在前，每页 20 条；支持全文搜索、阅读和定位原文。
- **记忆**：按消息所属回合浏览允许向读者展示的事件、认知和变动。搜索只使用相同的公开投影；私密字段、标签和隐藏数量不进入结果。普通纯正文不会被编造为记忆。
- 改写、换候选、删除、流式更新或切换聊天后，失效的列表和阅读页会停止展示旧内容。刷新重新读取原消息；导航不自动加载其他历史或切换会话。原消息节点未挂载时会明确提示。
- **通信**进入联系人；**生图／语音**进入原生扩展设置；**主题**进入原版主题配置；**图鉴**进入内置表情；**协议**进入回复与行动配置；**应用**进入全部扩展；**设置**打开原版统一设置页。打开入口不发送消息或自动生成。缺少对应扩展时明确报告。
- 侧栏也提供“会话手记”和“公开记忆”，隐藏桌宠时仍可使用。尚未接入的档案编辑、世界生成等业务继续标明待接入。
- 阅读错误增加中文说明，并保留解析器的安全错误码；不会把原始内部载荷或错误详情作为后备内容显示。这是诊断改进，尚不能据此认定用户先前的泛化错误已解决。

这些历史页只读、临时建立列表，不新建记忆库，不修改消息、当前状态或提示词。生成期间可以浏览；行动建议按明确选定的续接／替换／直发模式执行。

alpha.4 的回底快捷键、编辑区底部保存／取消、生成期间菜单解锁与原生工具入口全部保留。消息和桌宠素材、原版几何及动画姿态没有更换；焦点、隐藏和重试生命周期按上述修复更新。

## 消息操作

所有已加载消息下都有重骰、继续、更多。历史位置会自动删除后续消息再生成：AI 重骰重写选中条；用户消息重骰从该条生成；继续保留选中条并生成下一条。

“继续设置”可以自定义自动发送的用户消息。非空时通过宿主输入框和普通生成流程提交；留空直接请求下一条。输入框已有草稿、模型断开、正在生成或编辑时会拒绝操作。删除前验证会话、消息、候选和数量；后续历史未完整加载时不删除。删除或保存失败会报告部分完成并停止生成。

更多保留原生编辑、分支、复制、单条删除、范围回溯和扩展消息按钮。返回原生界面会移除扩展布局、监听及自有节点，恢复由扩展接管的装饰样式。

## 阅读与回合记录

从任意已载入消息的“更多”打开，提供正文、本回合、行动、心声与核验、世界扩展五个页面：

- 普通消息可直接阅读；结构化回复只提取正文，保留段落并统计可见文字。阅读排版使用宿主 Markdown 与净化器，不再次运行角色卡正则。原消息、原生富文本卡片和消息数据不改写。
- 本回合记录使用原 Foundation r243 的 `memory/5` 权限投影器。只有明确允许向读者输出的记录才能出现；父级、字段及嵌套权限全部保留检查。公开记录页不显示内部任务、私密记录、待办 / 倒计时壳或隐藏数量；心声与核验单独展示。旧格式没有所需权限时明确显示不可用。
- 记录属于选中消息的历史回合，不是当前状态总表。本版不推断玩家身份或别名，不写变量、不提交记忆；心理显示保持关闭。
- 行动按当前明确选择的续接／替换／直发模式执行；默认续接。执行前重验会话、消息与输入框；选历史行动不回溯消息。只有选择直发模式后再点行动才调用原生发送。
- 结构化回复损坏时不将整段内部载荷当正文显示；如果正文已完整闭合但后续字段未完成，正文仍可阅读，记录和行动分别报告错误。

15 个原始纯解析 / 投影模块逐字节保存在 `vendor/foundation`，来源和 SHA-256 见 `provenance.json`。`npm run build:reader` 生成无动态求值的浏览器模块；`npm test` 先核对来源哈希和构建一致性。基础叙事预设已适配酒馆；原插件设置页的实时装配、状态、身份绑定和生成提交闭环继续分批移植；本版只接通其中三个心声方向的实时选择。配套预设不自动读取 Tavo 存档。

## 字体与素材

默认字体立即可用。原 THM 字体从固定资源提交下载，SHA-256 校验后保存宿主本地文件，读回验证后启用。下载不阻塞聊天；侧栏显示状态并提供重试。原字体未放入主安装树。主题素材来自 Tisya THM 0.2.6，字体许可证见 `assets/FONT-LICENSE.txt`。

新增消息、桌宠及手机素材取自项目 r243 原资源：83 张 PNG 以原尺寸无损转换成 WebP，并逐像素核对 RGBA 一致；6 个 SVG 保留原文件。总计约 38.57 MB，更新时需下载。来源和哈希见 `assets/visual/provenance.json`。六张新增表情保持原 PNG 字节（约 680 KB），源路径、尺寸与 SHA-256 见 `emotion-assets.json`。15 个原版几何／动画及显示模块保存在 `vendor/visual`，3 个正文模块保存在 `vendor/typography`；构建时核对原文件哈希。素材加载失败会显示重试入口。

alpha.11 另保留 3 个原版消息界面源文件于 `vendor/reply-ui`，并接回 2 个原控制 SVG。`tools/build-reply-ui.mjs` 从原文件提取模板、账页渲染与按钮样式，只适配当前文档对象和共用字体名；`npm test` 校验源文件、图标哈希与生成结果。

## 显示设置的保存范围

新增自定义值仅存于宿主全局 `extensionSettings["缇斯亚界面"].显示区块.extensions`。字段沿原版 `chat-effects-options` 与 `journey-options`：背景特效模式为自动轮换／自选组合／关闭；五种背景及点触涟漪为布尔；上条落点为顶部／底部；两个默认开合为收起／展开；旅程外观为日间／夜间。缺失只读继承，合法 `false` 不回填。原动态效果、桌宠、联系人分组、行动设置等字段不改变。

保存调用目标 APK 的原生 `saveSettings()`，只有返回 `true` 才显示已保存。失败时保留本次值与错误，不撤销已有有效设置；原生若报告冲突应先处理原生错误。读旧消息／开图鉴不初始化或写状态；展示不代表正式状态内核已完成。

## 验证依据与限制

已对用户提供的 TauriTavern 2.3.0 APK 静态解包，从 Rust 动态库的 Brotli 资源中恢复实际前端。核心 HTML、CSS、布局防火墙、生成入口和附件处理等 21 个资源与源提交 `a1855be4a4f8b6ee7cd0374a84dbb3709c3e5375` 逐字节相符。

- `npm test`：163 项测试通过。新增动态编译、16 组原生心声／输出组合、配置作用域、失败保存、并发修改、方案管理及原版设置 UI 的回归；已有任务／待办、心声、公开权限及视觉检查保留。
- alpha.6 的 Chromium 153 排版检查使用解包 APK 的 HTML / CSS、旧主题和布局防火墙，在 320、360、390、768px 下检查原生编辑栏和原资源 Canvas。修复前的启动失焦夹具不响应戳戳；修复后进入歪头帧，Canvas 像素变化，泡泡保持在视口内。
- 本版使用 Chromium 138，在实际 APK 前端和净化器夹具中检查 360、709px：原版设置导航、人称保存、心声关闭、主题排版保存及重新打开读回；随后验证当前正文立即更新，同时保持原任务折叠状态。并回归两个原图标真实解码；任务／待办按钮、账页核验和心声翻页实际点击；外层和内层折叠及心声页码在重挂后保留；无心声时无游离动物，空世界卷轴初始收起，长心声气泡自然增高且无横向溢出。已查看渲染截图。宿主服务仍为离线夹具，不代表 Android 实机。
- alpha.9 的表情解码、世界分栏、自适应高度、字体、显示配置及图鉴排版检查，以及 alpha.8 的火焰和行动检查，保留为历史证据。alpha.10 的手机截图已确认任务／待办缺失、心声动物错位；本版针对此失败恢复原组件，更新后的 Android 显示仍待反馈。
- 用户截图中的整页高编辑栏仍记为旧版设备失败。本地组合未完整复现同等高度；本版增加了显式高度上下界，并检验旧主题和 1100px 冲突高度，手机端仍待更新后反馈。
- 本版未验证 Android 键盘动画、系统文件选择器、真实模型请求或全部第三方扩展。此前的原生附件事件及 10 组 DOM 模拟是历史证据，不升级为本版设备验收。
- 既有 `TISYA_READER_INVALID` 如仍出现，需对应原始输出才能核定协议原因；本版仍保留原输出协议。
- 原生管理表单仍由宿主编辑器负责；世界书身份绑定、全部管理字段的重新编排尚未完成。

开发环境可将此目录作为全局扩展根目录。普通用户使用宿主扩展安装器连接上述仓库；已安装的用户直接更新并重启，不必重装 APK。
