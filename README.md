# 0.2.0-alpha.22 · 前文记忆与心声表情

默认把近期历史窗口以前的记忆块及其场景、状态锚，按原消息顺序放入近期历史之前。只读取当前聊天有效候选，每次发送重新读取；编辑、删除、重骰不会继续使用旧副本。配置→上下文范围可关闭注入；上下文一览显示实际注入条数及缺少记忆块的旧回复。缺块不自动编造摘要，超预算明确停止。

心声首尾使用一条规则：开篇接输入，收篇逐条评论正文新增的具体变化，观点不得重复。每条必须选择真实表情图鉴中的名称，不再允许心声 null。发送历史时移除已完成旧回复中的首尾心声，原消息与显示不改；继续生成中的尾稿完整保留。

更新扩展并重启即可；旧 alpha.13 / alpha.20 预设通过现有宏读取新版规则，无须重新导入预设。alpha.21 的读者记录、角色心理开关、七个快捷位与更多、常用语增删改及追加输入均保留。

参考范围见 docs/memory-injection-reference.md；本次是原记忆块注入，没有接入外部向量服务或另建数据库。token 实验仍在 docs/token-study。

验证：244 项自动化检查通过，包含 70 条历史的实际请求装配、来源去重、开关、预算、删改及重骰。完整提示词的无历史独立生成及浏览器表情检查见 docs/alpha22-validation.json；用户模型接口和 Android 设备尚未实测。
