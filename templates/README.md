# 手机世界与角色初始化模板

`phone-world.json` 与 `phone-character.json` 是本轮同一手机解析器合同的未填写骨架，不是演示存档。全局模板书由 `engine/template-book.mjs` 使用这两份 JSON 生成，条目保持关闭原生自动注入。

世界定义用唯一的 `<手机世界>…</手机世界>` 包裹，保存在普通资料书的 `【手机世界】名称` 条目；角色个人初值用唯一的 `<手机初态>…</手机初态>` 包裹，可附在基点书 `【角色】名称` 原文末尾。其他人物档案原文照常保留。

模板仅在新世界／新角色设计及首次初始化草稿中引用，不随普通剧情回合注入。使用者在用户身份页底部选择当前聊天的资料书及手机世界定义。选择与编辑不会重置已存在的手机存档。

`null` 表示未提供，`0`、`false` 和空列表各有独立意义。世界编号、角色编号及名称须填写实际定义后才能初始化；故事时间必须带时区，不从设备时钟补齐。金额使用整数分，不生成虚构余额、联系人、商品、照片或音源。

选择原生变量或表单作为结算归属时，禁止创建第二份可写资金账本。完整字段、类型与业务校验由 `phone-life-config.mjs` 统一维护。
