# 手机世界与角色初始化模板

`phone-world.json` 与 `phone-character.json` 是本轮同一手机解析器合同的未填写骨架，不是演示存档。全局模板书由 `engine/template-book.mjs` 使用这两份 JSON 生成，条目保持关闭原生自动注入。

世界定义用唯一的 `<手机世界>…</手机世界>` 包裹，保存在普通资料书的 `【手机世界】名称` 条目；角色个人初值用唯一的 `<手机初态>…</手机初态>` 包裹，可附在基点书 `【角色】名称` 原文末尾。其他人物档案原文照常保留。

模板仅在新世界／新角色设计及首次初始化草稿中引用，不随普通剧情回合注入。使用者在用户身份页底部选择当前聊天的资料书及手机世界定义。选择与编辑不会重置已存在的手机存档。

`null` 表示未提供，`0`、`false` 和空列表各有独立意义。世界编号、角色编号及名称须填写实际定义后才能初始化；故事时间未提供时保持未知；填写起点时须带时区，不从设备时钟补齐。金额使用整数分，不生成虚构余额、联系人、商品、照片或音源。

选择原生变量或表单作为结算归属时，禁止创建第二份可写资金账本。完整字段、类型与业务校验由 `phone-life-config.mjs` 统一维护。

## 完整世界书与入口

`tisya-template-book.json` 是包含两份骨架、使用说明与完整字段格式的完整原生世界书 JSON；全部条目 `disable: true`。它与运行时 `bundledTemplateEntries()` 内容一致，不含用户实例。首次打开用户身份页会按名称准备“缇斯亚模板书”；已有书只补缺失内置条目，用户改文和其他条目保留。也可以先导入这份书并编辑；新内容创作会读取已存在的同名书，不要求先打开身份页。

`tableGenesis` 的新世界、补充新设定、新人物以及基点人物设计与 `templateInit` 的角色卡初始化草稿读取该书；修订既有定义、普通叙事、归档、手工角色保存和模板通用／复用模式不读取。没有安装书时，创作草稿明确标记使用随插件打包的骨架；已经有书但读取失败会报错，不以旧骨架顶替。

生成内容仍进入原有可编辑草稿，按原有保存流程确认。世界定义需另存为 `【手机世界】名称` 条目，角色初态附在选中 `【角色】` 档案中；本阶段不会把未确认的模型草稿自动写成手机运行状态。已保存模板在草稿生成后发生变化时，保存会要求重新读取和核对。

完整中文字段签名、整数单位、引用与隐私约束见 `phone-fields.md`，内容亦作为第四条说明写入完整模板书。

同世界同来源的应用清单、应用名称与画风可刷新显示而不重置；更换世界编号应另开新聊天。已存档的财务机制、结算归属或故事起点变更需要显式迁移，当前阶段拒绝直接覆盖。
