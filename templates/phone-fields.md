# 手机初始化字段格式

以下是类型签名与填写约束，不是可直接粘贴的实例 JSON，也不提供任何人物、余额、债务或媒体事实。两份骨架是唯一的待填事实模板；没有依据的数组保持 []，未知且允许缺失的值保持 null。每一条实际世界/角色来源只允许一个完整对应标签，标签内必须为标准 JSON，不加注释、尾逗号或额外字段。

## 通用类型与单位

编号＝非空稳定字符串，同一列表不重复；引用必须写被引用项的编号，不用显示名字替代，不用复制来源的内容。书籍定位采用书名与条目 UID；修改同一条档案保留 UID。世界编号与角色编号/姓名填好后才可初始化，模板中的 null 不是运行实例。
文字＝字符串；金额＝非负整数，单位为当前货币的最小单位（小数位固定 2，100 个最小单位＝1 个货币单位）；余额/商品单价/库存允许 null 表示未知，不能把未知当零。正本金须大于 0。时间＝包含 Z 或显式 ±HH:MM 时区的 ISO 字符串；故事分钟＝相对世界“时间.起点”的非负整数分钟，不是设备时间戳。年利率基点为整数，100 基点＝1%，10000 基点＝100%；最大 1000000 基点。圆角单位为 CSS 像素，整数 0–40；颜色使用 #RGB、#RGBA、#RRGGBB 或 #RRGGBBAA。

## 世界完整签名

{格式:"缇斯亚手机世界/1",世界编号:编号|null,名称:文字|null,应用:[应用名],应用名称:{应用ID:显示名称},画风:{背景:颜色|null,面板:颜色|null,文字:颜色|null,强调:颜色|null,圆角:整数|null},时间:{起点:时间|null},结算归属:"手机账本"|"原生变量"|"表单"|null,货币:货币定义|null,金融:{贷款:贷款规则|null,理财:[理财产品],商城配送费:金额|null,外卖配送费:金额|null},商品:[商品],地点:[地点],交通:交通定义|null}
应用名接受 微博、钱包、商城、外卖、相册、音乐、地图、日历，或对应 weibo、wallet、shop、food、album、music、map、calendar。应用名称的键只用这 8 个英文 ID，值为实际界面名称；空对象不改名。应用清单决定可用应用。
货币定义＝{名称:文字,符号:文字,小数位:2}。
交通定义＝{步行速度:正数|null,骑行速度:正数|null,公共交通速度:正数|null}；单位为地图单位/故事分钟，未提供速度的方式不可出发。
贷款规则＝{年利率基点:整数|null,期数:[1–120 的整数],每期天数:1–366 的整数|null,每年计息期数:1–366 的整数|null,最低本金:正金额|null,最高本金:正金额|null}。新贷款采用等额本金；首期最高，之后随剩余本金减少。每期利率由年利率和“每年计息期数”计算，不能把“每期天数”默认为一个月或暗补 12 期。规则不完整不开放借款，最高本金不得低于最低本金。确认前需展示真实报价与逐期明细。
理财产品＝{编号:编号,名称:文字,年利率基点:整数,说明:文字}。这是世界提供的产品，不是角色已持仓。
商品＝{编号:编号,名称:文字,说明:文字,单价:金额|null,库存:非负整数|null,类别:"实物"|"食品",店铺编号:编号|null,地点编号:地点编号|null,封面:插画标记或空字符串,标签:[文字]}。类别区分商城与外卖，库存为件数；地点引用世界的地点列表。空/null 不是免费或无限库存的假定。
地点＝{编号:编号,名称:文字,说明:文字,横坐标:有限数|null,纵坐标:有限数|null,类型:文字,已知:布尔值}。坐标与交通共用地图单位；已知只按角色已有依据填写，目录列出不意味着角色知道。当前位置必须引用这里的地点。

## 角色完整签名

{格式:"缇斯亚手机角色/1",角色编号:编号|null,姓名:文字|null,账号:[账号],当前账号:本人账号编号|null,钱包:{账户:[钱包账户],默认付款账户:钱包账户编号|null,默认收支账户:钱包账户编号|null,信用卡:信用卡|null,贷款:[已有贷款],理财:[已有理财]},联系人:[联系人],微博:[微博],相册:[相片],音乐:[歌曲],歌单:[歌单],日程:[日程],当前位置:地点编号|null}
债务可作为已有贷款数组的旧别名，但与“钱包.贷款”只能写一处；新骨架统一使用钱包.贷款。账户、联系人、微博、相册、音乐和日程可以全部为空，不补演示人物或资产。
账号＝{编号:编号,名称:文字,用户名:文字,人物编号:编号|null,本人:布尔值,简介:文字,颜色:颜色|null,标签:文字,关注:[账号编号]}。“本人”必须明确 true/false；本人账号的人物编号应为当前角色编号，null 时明确归当前角色。当前账号必须是本人账号，null 时从已登记的本人账号选择；无本人账号则保持 null。关注编号引用已登记账号。
联系人＝{编号:编号,名称:文字,人物编号:编号|null,账号编号:账号编号|null}。人物编号是稳定人物引用；网络账号未知可留 null，不强造账号。联系人不自动授予微博或私人相册的知情权限。
钱包账户＝{编号:编号,名称:文字,余额:金额|null}。默认付款账户及默认收支账户须指向钱包账户；多账户但未明确默认时，交易由用户实际选择。不把授信额度或贷款本金重复计为余额。

## 信用卡、贷款与理财持仓

信用卡＝{编号:编号,名称:文字,额度:金额,账单日:1–28 的整数,到期日:1–28 的整数,溢缴款:金额,消费:[信用消费]}。没有信用卡就填 null。总未还债务由逐笔消费汇总，不能超过额度；未填写消费表示没有已知未结消费，不生成虚构账单。
信用消费＝{编号:编号,订单编号:编号|null,金额:金额,原始债务:金额,剩余债务:金额,已还:金额,已退:金额,预付款:金额,账单分钟:故事分钟,到期分钟:故事分钟}。没有可引用手机订单的历史消费，订单编号留 null。必须满足 原始债务+预付款=金额，剩余债务=max(0,原始债务−已还−已退)，已还不大于原始债务，已退不大于金额。溢缴款不是新收入；退款先冲减原债务，剩余进入卡内溢缴款。
已有贷款＝{编号:编号,本金:正金额,期数:正整数,年利率基点:整数,总利息:金额,总应还:金额,已还:金额,剩余本金:金额,分期:[贷款分期],收支账户:钱包账户编号|null}。已有贷款必须有实际逐期明细，不能只填一个总债务并让系统猜分期。
贷款分期＝{期号:正整数,本金:金额,利息:金额,已还:金额,到期分钟:故事分钟}。每期应还=本金+利息；已还不大于该期应还。总应还等于各期应还之和，贷款已还等于各期已还之和；还款先覆盖当期利息，再减少本金。剩余本金须与逐期剩余本金一致。总本金、总利息和期数按实际合同核对，不虚构逾期罚息或自动扣款。
已有理财＝{编号:编号,产品编号:理财产品编号,本金:正金额,已结算收益:金额,申购分钟:故事分钟,结算分钟:故事分钟}。产品编号必须出现在世界金融.理财中；持仓不是银行可用余额，收益仅记录有依据的已结算部分。
金融结算归属只选一个。手机账本可按已配置条件支付/借款/理财；原生变量或表单归属不另建可写资金账本。未配置时间、货币、账户或规则时，相应功能明确不可用，不以默认值补齐。

## 微博、相册与音乐

微博＝{编号:编号,作者:账号编号,正文:文字,可见范围:"公开"|"关注者"|"私密",相片:[相片编号],公开授权:[相片编号],转发来源:微博编号|null,歌曲:歌曲编号|null,原始点赞数:非负整数|null,时间:时间|null}。作者、媒体、转发与歌曲都引用同一初态已登记条目；转发不能指向自己。公开授权只表示该条微博可以分享其列出的私人原件，不把相册原件改为公开，也不代表其他帖子获授权。私密相片只能由实际拥有者或其本人账号分享；公开/关注者帖子使用私人照片必须有对应授权。未知点赞数、未知原发布时间保持 null。
相片＝{编号:编号,名称:文字,归属:当前角色编号或账号编号|null,可见范围:"私密"|"公开",来源:"文件"|"插画",插画:插画标记,媒体类型:MIME 字符串}。归属 null 明确归当前角色，即使没有网络账号也可持有相册。相册原件不接受“关注者”，分享范围在微博里处理。可见范围默认私密。来源为文件时，真实文件须在手机中导入并持久保存；条目编号/名称本身不会生成图片，初始化资料书不携带文件二进制。
歌曲＝{编号:编号,歌名:文字,作者:文字,专辑:文字,封面:插画标记或空字符串,音源:媒体文件编号|null,时长:非负有限数|null}。时长单位为秒；音源是已导入并保存的真实音频媒体编号，不是歌曲编号、网页地址或假定可用的网络链接。音源为 null 或文件不可读取时仅有曲目信息，必须选择实际音频才可播放，不宣称已经播放。
歌单＝{编号:编号,名称:文字,歌曲:[歌曲编号]}，引用已登记曲目，不重复复制音源。相册/微博共用相片编号，音乐/微博共用歌曲编号；私有文件不能因被引用就绕过归属或公开授权。

## 日程与世界变更

日程＝{编号:编号,标题:文字,时间:时间,地点:地点编号|null,参与者:联系人编号或账号编号|null,状态:"个人"|"待确认"|"已确认"|"已取消"}。标题至多 100 字符；有日程具体时刻时世界必须已有时间起点；分钟轴由同一世界起点计算。参与者存在不等于对方已答应，只有已有明确依据才能填已确认；待确认保留邀请状态。地点和参与者使用已有编号，不由显示名称猜测。
选择与保存资料书、角色档案不会重新套用初值。正式手机初始化是独立显式操作。更换世界编号应另开新聊天；同一世界、同一来源的应用列表、应用名称与画风变更可刷新显示而不重置个人状态。已存档的货币、结算归属、时间起点或金融机制变更需要迁移；当前实现拒绝直接覆盖，保留原档。世界/角色条目移动或 UID 改变也属于来源变化，应先核对归属，不能凭同名接管旧手机。
